# 회원→게스트 전환과 콕 재고 메모

- 작업 시각: 2026-11-19 15:48 (한국 시간)
- 관련 요청: 166, 167
- 공개 주소: https://kokkiri.kokkiri-badminton.workers.dev/

## 구현 내용

### 정회원에서 게스트 전환

- 시드현황 수정 화면의 회원 탭에 `게스트로 전환` 버튼을 추가했다.
- 선택한 회원의 이름, 점수, 출석, 승, 패, 이전 점수, 점수 보호 상태를 게스트 행으로 그대로 옮기고 기존 회원 행은 과거 대진 참조를 위해 숨긴다.
- 운영진 권한이 남은 회원과 같은 이름의 활성 게스트가 있는 회원은 전환하지 않으며 이유를 안내한다.
- 회원↔게스트 전환을 여러 번 반복해도 모든 과거 ID를 동일 인물로 추적하는 공통 계보 처리를 추가했다. 대진 마감·취소, 점수 그래프, 누적출석, 출석점수 정정, 주간 표시, 긴급교체가 같은 기준을 사용한다.
- 운영진 임명·해제와 회원 전환이 동시에 실행될 때 명단 버전 충돌로 한쪽만 반영되도록 보강했다.
- 마이그레이션 `0025_member_to_guest.sql`로 게스트의 이전 회원 ID와 `demote` 변경 이력을 보존한다.

### 콕 재고 메모

- 콕 재고 표에 `메모` 열을 추가했다. 운영진은 편집 중 메모 작성·수정 창을 열 수 있고, 회원은 저장된 메모를 조회할 수 있다.
- 메모는 행당 최대 5,000자이며 날짜·변동 개수와 함께 재고 스냅샷과 변경 이력에 저장된다.
- 배포 전 화면처럼 메모 키를 보내지 않는 구버전 화면은 같은 행의 기존 메모를 자동으로 유지하고, 새 화면에서 빈 메모를 명시한 경우에만 삭제한다.
- 배포 직전 저장 요청의 재시도도 새 형식으로 정규화해 같은 저장 결과를 돌려준다.
- 기존 메모를 합친 실제 저장 본문이 256 KiB를 넘으면 상태와 변경 이력을 바꾸지 않고 413으로 거절한다.

## 검증

- `node check-shuttle-inventory.mjs` 통과: 메모 저장·조회, 구버전 수량 저장 시 메모 보존, 배포 전 저장번호 재시도, UTF-8 병합 크기 제한과 원자성 확인.
- `node check-shuttle-inventory-ui.mjs` 통과: 회원 메모보기, 운영진 메모 작성·적용·저장, 반응형 메모 창 확인.
- `node check-login.mjs` 전체 통과: 정산·마감취소·점수·출석·권한·회계·재고·회원 접근 회귀 없음.
- Astra 최종 검토 승인: 반복 전환 계보, 동시 권한 변경, 출석 정정, 과거 이름 충돌, 구버전 재고 호환과 크기 제한까지 승인.
- 실제 운영 데이터는 시험 전환하거나 수정하지 않았다.
- 공개 배포와 운영 D1 마이그레이션 적용 여부는 GitHub push 후 확인한다.
