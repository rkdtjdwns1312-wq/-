# 요청 124·125 — 모바일 버튼 가독성과 대진 수정 맞교환

## 요청과 계획

- 모바일에서 한 줄 버튼의 글자가 잘리거나 어색하게 두 줄로 갈라지지 않도록 글자 크기·여백·버튼 그룹 배치를 조정한다. 320/360/390/430px 및 운영진 좁은 본문, PC를 검증한다.
- 대진 수정에서 같은 라운드의 기존 선수를 선택하면 두 자리 맞교환. 휴식자를 선택하면 빠진 선수가 휴식으로 이동한다. 다른 라운드는 유지하고 교환으로 변경된 경기의 기존 승패·진행 상태만 초기화한다.
- 기존 예외 중복 출전자 데이터는 삭제하지 않는다. 교환이 모호하거나 같은 경기 중복을 만들면 저장 전 안내한다. 승패 보존 목적의 긴급교체는 별도 기능으로 유지한다.

## 시작 상태와 모델 분담

- 작업 트리 clean, 최신 pull 성공(기본 샌드박스 DNS 오류 후 승인된 네트워크로 재시도). 원격은 7467ab3, 로컬에 미전송 문서 커밋 2eca4a3 존재.
- 이전 미전송 문서의 개인별 점수표를 제거하고 집계만 남긴 fc1f8b5로 해당 커밋만 amend. 개인별 운영 정보는 원격에 전송하지 않는다. 변경 전 전체 check-login PASS.
- GPT-6 Luna: CSS 개선(기존 지정 GPT-5.6 Luna는 현재 사용 불가). 본체: 맞교환/회귀 검증/통합·기록. GPT-6 Astra 최종 검토 PASS.

## 구현과 변경 파일

- `boards-style.js`, `operator-nav.js`: 모바일 버튼은 글자·패딩을 줄이고 한 줄을 유지하며 버튼 묶음은 버튼 단위로 다음 줄로 이동. 운영진 사이드바는 82px, 본문 왼쪽 공간 94px로 다섯 글자 메뉴도 표시. 350px 이하에서 본문/팝업 여백 조정.
- `live-style.js`, `score-history-style.js`: 실시간대진 긴 이름은 별도로 자연스럽게 줄바꿈하고 그래프 탐색 버튼 묶음은 좁은 화면에 맞춰 배치.
- `schedule-tools.js`: 같은 라운드의 두 위치를 맞교환하고 휴식자 선택은 휴식 명단을 재계산. 기존 예외 중복 출전자 중 대상이 모호하면 거절, 같은 코트에 명확한 대상이 있으면 그 자리 우선. 목적지 경기 내 중복도 변경 전에 거절.
- `boards-client.js`: 편집 안내에 맞교환·휴식 이동·변경 경기 결과 초기화 및 긴급교체 구별을 명시.
- `check-schedule.mjs`, `check-client-audit.mjs`, `check-operator-nav.mjs`: 교환/휴식/늦참/중복 충돌/실제 편집 핸들러/저장 후 유지 및 모바일 스타일 회귀 검사.
- 다른 홈페이지의 교실·선생님 코드 요청은 사용자가 취소하여 수정하지 않음.

## 검증 및 배포

- 전체 `node check-login.mjs` PASS. 로컬 메모리 DB 외 운영 DB에 시험 입력하지 않음. 새 마이그레이션이나 점수 정산 로직 변경 없음.
- 실제 편집 화면 320/360/390/430/1280px에서 버튼 잘림·페이지 가로 넘침 없음. 320px 대진 상세와 실시간대진 열기 확인창도 확인. 버튼 글자는 한 줄, 버튼 묶음은 다음 줄로 배치됨.
- 로컬 편집 화면에서 다른 코트 선수를 선택해 두 자리 맞교환 확인 후 저장 성공. 서버 회귀 검사에서 재조회된 명단 및 다른 라운드 보존 확인.
- Astra 독립 검증: 변경 경기만 승패·진행 초기화, 다른 경기 보존, 저장 시 점수 불변, 미입력 마감·오래된 저장 거절, 교환 선수 기준 정산 PASS. 320px 사이드바 실측 PASS.
- 로컬 서버는 샌드박스 소켓 제한으로 최초 접속 실패하여 승인된 실행으로 다시 열어 검증. 브라우저 도구 자체의 별도 통계 전송 403은 사이트 오류와 구분.
- GitHub push 및 공개 배포 확인 대기.

## 핵심 명령

모바일 버튼의 한 줄 가독성을 개선하고 대진 수정 시 선택한 선수와 기존 선수의 자리를 맞교환한다.
