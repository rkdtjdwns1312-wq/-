# 회원 화면 운영진권한 버튼과 비밀번호 전환
- 날짜·시간: 2026-09-12 00:33 (KST)

## 요청
일반 회원 홈페이지 오른쪽 아래에 '운영진권한' 버튼을 만들고, 버튼을 누르면 비밀번호를 입력해야 운영진 권한 페이지로 전환되도록 해달라는 요청.

## 구현 내용
- 회원 화면(운영진이 아닌 화면) 우측 하단에 '운영진권한' 버튼을 고정 배치.
- 버튼 클릭 시 접근성을 갖춘 비밀번호 입력 대화상자(dialog)를 표시.
- 입력값은 `POST /api/operator-login`으로 전송.
- 서버는 입력값과 환경변수 `OPERATOR_PASSWORD`를 SHA-256 해시로 상수시간 비교하여 검증(비밀번호는 서버 비밀 환경변수로만 보관).
- 비밀번호가 일치하면 기존 운영진 주소로 이동.
- 요청 origin이 홈페이지와 다르면 403으로 거절.
- 입력값이 1KB를 초과하면 413으로 거절.
- IP를 해시한 버킷 단위로 15분간 5회 시도(정답 포함 모든 시도를 셈) 후 429로 제한. 제한 정보는 D1 테이블 `operator_login_limits`(마이그레이션 `drizzle/0002_operator_login_limits.sql`)에 저장하며 원문 IP는 보관하지 않음.
- 인증 성공 시 해당 버킷의 시도 횟수를 초기화.
- 비밀번호와 운영진 주소는 회원 화면 HTML/JS에 포함하지 않음.
- 기존 운영진 비밀 링크와 게시글 저장 권한 검사(`x-kokkiri-editor` 헤더)는 그대로 유지.

## 검증
`check-login.mjs` 신설. 오답 401, 정답 200 및 운영진 주소 응답, 외부 origin 403, 오답 5회 후 429, 제한 만료 후 재허용 200, GET 요청 405, 환경변수 미설정 시 503, 회원 HTML에 비밀값 미노출, 기존 운영진 경로 200, 무권한 저장 403을 확인하여 모두 통과.
