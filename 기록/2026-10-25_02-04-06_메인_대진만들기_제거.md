# 요청 135 — 메인 대진 만들기 제거

## 요청·계획

- 대진표 메뉴에 만들기가 있으므로 메인에서는 대진 만들기 버튼과 안내 문구를 제거한다.
- 홈의 `새로운 게임을 준비하시나요?`, `+ 대진 만들기`, homeNew 이벤트만 제거. 대진표 내부 newPost 및 대진 생성 기능은 그대로 유지한다. 메인4개 메뉴·회계장부·MVP도 유지.
- GPT-6 Luna에 좁은 UI 수정/검사를 위임하고 Astra 최종 점검 후 전체 검사·commit·push·공개 확인한다.
- 진행 중. 직전132~134는634cec8 배포 확인 중이며 운영 이름 정정은 별도로 수행 예정.

## 구현·검증

- Luna가 `boards-client.js` home의 안내/버튼/클릭 핸들러만 제거. `check-member-ui.mjs`의 실제 홈 함수 검사에 운영진/일반 홈과 기존 대진표 목록 버튼 보존 회귀 검사 추가.
- focused 검사와 diff 검사 PASS, Astra 최종검토 차단 문제 없음. 홈4메뉴/회계장부/MVP/접근권한/대진표 내부 생성 유지.
- 본체 전체 검사 후 배포/공개 화면 확인 예정. DB 변경 없음.
