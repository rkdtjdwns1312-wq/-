# 출석 승패 점수 누적과 시드 자동 반영
- 날짜·시간: 2026-09-12 01:10 (KST)

## 요청
두 단계로 요청함.
1. 회원 이름·점수·시드를 기억하고 변화값을 누적 기억하며, 점수에 따라 시드(알파벳)가 자동으로 시드현황에 반영되게 해달라. 대진표에 이름이 있으면 출석 +1, 대진마다 승패 버튼으로 기록하고, 모든 라운드 승패 계산 후 승 +1·패 -1·출석 +1을 합산해 기존 시드표에 반영하여 이를 기반으로 등수·점수·시드가 변동되게 해달라.
2. 앞서 첨부한 `콕끼리 랭킹_260418.xlsx`는 오래된 자료이므로, 현재 자료인 `콕끼리 시드 관리표.xlsx`를 기준으로 저장해달라.

## 구현 내용
- D1 테이블 3개 신설(`drizzle/0003_rankings.sql`)
  - `ranking_members`: 회원별 점수·시드·순위·이전 순위·출석·승·패.
  - `ranking_settlements`: 대진표별 1회 정산 기록. operation을 UNIQUE로 두어 중복 정산 방지.
  - `ranking_events`: 회원별 정산 이력(출석/승/패 점수, 정산 전후 점수·순위·시드).
- 초기 기준: `콕끼리 시드 관리표.xlsx` 1번 시트(작성기준 2026-09-10)의 회원 61명 이름·포인트·순위를 그대로 초기값으로 사용(`dist/server/rankings.js`의 initialRankingRows). 시드는 엑셀 값을 복사하지 않고 아래 점수 구간으로 자동 계산한다. 이 때문에 엑셀 시드 열이 A+인 주밤(115점)·로토(104점)는 계산값이 A로 달라진다(2026-09-12 Opus 검증에서 발견). 사용자가 같은 날 "A가 맞다"고 확인하여 자동 계산을 유지하고 명단 파일도 A로 맞췄다(요청 023, 커밋 280aa75). 이전 `콕끼리 랭킹_260418.xlsx`(29명, 2026-04-18 기준) 기준은 폐기. 2번 시트 '26-08-19 변경'은 빈 시트이며 사용하지 않음. 게스트 32명은 대진표에는 포함되지만 회원 랭킹 점수에는 반영하지 않음. 대조 결과 회원 61명·게스트 32명의 이름·시드가 홈페이지 명단(roster.js)과 모두 일치함을 확인.
- 시드 구간(점수로 자동 계산): S 150 이상, A+ 120, A 100, B+ 90, B 80, C+ 70, C 60, D+ 50, D 40, E+ 30, E 20, E- 0.
- 운영진 대진표 편집 화면에 코트마다 '앞 팀 승리'/'뒤 팀 승리' 버튼과 '대진·승패 저장' 버튼 추가. 모든 코트 결과 입력 후 '점수 반영 및 확정' 버튼으로 `POST /api/posts/:id/settle` 호출.
- 정산 규칙: 대진표에 이름이 있는 회원 출석 +1(1회), 경기 승 +1, 패 -1을 합산 → 점수순 재정렬 후 `ranking_members` 갱신(이전 순위 보존, 시드 자동 재계산) → `ranking_events` 이력 기록.
- 승패 미입력 코트가 있으면 400으로 안내. 정산 완료된 대진표는 이후 수정 불가(409). 같은 대진표 재정산 요청은 기존 결과를 반환하여 중복 누적을 방지. 상세 화면에 '점수 반영 완료' 배지 표시.
- 시드현황 화면: 회원 랭킹 표(순위, 변동 ▲/▼, 회원, 시드, 점수, 출석, 승, 패)와 게스트 탭, 이름 검색 기능 추가. `/api/people`은 랭킹 테이블의 최신 시드를 반영. `/api/rankings`는 source '콕끼리 시드 관리표.xlsx', sourceDate '2026-09-10'을 함께 반환.
