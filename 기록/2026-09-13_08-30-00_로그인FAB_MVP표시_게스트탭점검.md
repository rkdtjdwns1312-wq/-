# 로그인 사람 실루엣 버튼 + MVP 표시 개선(홈 배너·마감 제목) + 게스트 탭 점검

- 작업 도구: Claude Code (Opus 4.8 본체 — 구현·테스트·브라우저 하니스/라이브 점검)
- 관련 요청: 075(로그인 FAB), 076(게스트 탭 점검), 077(홈 MVP 배너), 078(마감 제목 유지)
- 이후 남은 작업은 사용자가 코덱스로 이어감.

## 1. 요청과 처리

### 075 로그인 사람 실루엣 버튼
- 회원 홈에 항상 보이던 '운영진권한'·'홈페이지관리자 권한' 두 버튼 → **작은 사람 실루엣 FAB(👤 SVG, 우하단)** 하나로. 누르면 팝업 메뉴에 두 항목(순서 교체: 운영진권한 위, 홈페이지관리자 권한 아래). 바깥 클릭·ESC로 닫힘.
- `boards-client.js`: loginButton → openLoginDialog + FAB/menu. `boards-style.js`: .access-fab/.access-menu/.access-item.

### 076 게스트 탭 승·패·변동·화살표 미표시 제보 → 코드 정상(데이터 0)
- 라이브 점검: 게스트 탭에 **출석·승·패 칸은 정상 렌더(값 0)**, 점수 화살표는 변동 없어 미표시. 회원 탭은 데이터 있는 회원(주밤 116▲1·로토 109▲5 승4 등 24명)에 승·패·화살표 정상.
- 원인: 068(게스트 정산) 이후 **채점된 정산 경기가 없어** 게스트가 0. 9/12 정모는 게스트 점수 기능 이전이고, 게스트는 랜덤 라운드만 뛰어 점수 대상이 아니었음. **코드 버그 아님.** 향후 게스트가 낀 대진을 마감하면 표시된다(068 배포 때 데이터 있는 렌더 검증 완료).

### 077 홈 MVP 배너 세로 + 금메달
- `.mvp-home`을 flex-direction:column로. "🥇 이번 정모 MVP"(위) / 명단(아래). ✨→🥇. 이름 공백 구분(join(' ')).

### 078 마감 시 제목 유지 + MVP 아래 작게
- `settleSchedule`이 title을 **원제목 그대로** 두고 mvp[]만 저장(기존엔 "…정모의 MVP …"로 제목을 바꿨음).
- 목록/상세는 preTitle 우선(`COALESCE(preTitle,title)` / `d.preTitle||d.title`)으로 원제목 표시 → 이미 마감된 9/12 정모 제목도 자동 정상화.
- 상세: 제목 아래 작은 MVP 줄(🥇 이번 정모 MVP + 이름 공백 구분, 반짝임). h1의 mvp-title(전체 반짝임)은 제거.
