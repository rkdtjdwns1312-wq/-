# 공지사항 표시 개선과 게스트 탭 표 형식 통일

- 작업 시각: 2026-09-12 10:05 ~ 10:35 KST
- 작업 도구: Claude Code (계획·최종 점검 Fable, 구현 Sonnet 서브에이전트 2개(순차), 검증 Opus 서브에이전트 1개)
- 관련 요청: 029, 030

## 1. 요청 번호와 요청 요약

- 요청 029: 공지사항의 디자인·글씨체를 홈 전체 분위기와 어울리고 가독성 있게 고쳐 달라. 제목도.
- 요청 030: 시드현황의 게스트 탭 표현이 회원 랭킹과 다르니 같은 형식(표)으로 맞춰 달라.

## 2. 계획 (Fable)

- 공지 본문(DB 내용)은 바꾸지 않고 **표시 방식**만 바꾼다. 운영진이 평문으로 쓰는 관습("1. 제목", "[소제목]", "▶ 항목", 들여쓴 이어짐 줄, "🔵 메모", "6월")을 규칙으로 정해 구조화된 HTML로 렌더링하고, 제목·소제목은 홈과 같은 Do Hyeon, 본문은 Noto Sans KR로 통일. 목록·상세에 초록 '공지' 라벨. 모든 텍스트는 이스케이프(주입 방지).
- 게스트는 점수 누적 대상이 아니므로(사용자 결정, 기준표 "반영X") 기준표 점수를 명단 데이터에 넣어 회원 표와 같은 열(순위·변동·게스트·시드·점수·출석·승·패)로 보여 주고, 변동·출석·승·패는 "-". 점수 내림차순 안정 정렬 후 순위, 검색해도 순위 유지.
- 두 작업은 같은 파일(`boards-client.js`)을 건드리므로 Sonnet을 순차로 실행하고 Opus 검증은 한 번에.

## 3. 수행 내용과 변경 파일

- Sonnet A(공지): `dist/server/boards-client.js` — client 함수 안에 `noticeHTML(body)` 추가(줄 단위 규칙 → h2.nb-section / h3.nb-sub / p.nb-month / ul.nb-list li / span.nb-cont / p.nb-note / p), 상세 화면 본문에 적용, 공지 제목 위 '공지사항' 라벨, 목록의 공지 항목에 '공지' 라벨과 Do Hyeon 제목, 공지 편집기에 작성 요령 안내 한 줄. `dist/server/boards-style.js` — `.notice-body`(white-space normal, 46em, 1.04rem/1.85), `.post-label`, `.post-notice`, `.nb-*` 스타일, 모바일 규칙.
- Sonnet B(게스트): `dist/server/roster.js` — 게스트 32명에 `points` 추가(기준표 `자료/콕끼리 시드 관리표.xlsx` 2026-09-10에서 읽음, 회원 61명 객체는 바이트 동일). `boards-client.js`의 `seeds()` 게스트 분기를 회원 표와 같은 `ranking-table`로, 표 위에 "게스트 점수는 기준표 값이며 누적 반영 안 됨" 안내. `check-login.mjs` — 게스트 32명·정수 점수·몽구 125·우니 17 검사 추가.
- Opus 수정 1건: 들여쓴 이어짐 줄을 직전 항목에 붙일 때 문자열 `replace` 치환문에 본문을 직접 넣어 `$&` 등이 해석되던 버그 → 함수 치환으로 수정.
- Fable 수정 2건(Opus 보고 반영): 목록 기호 중 `-`·`–`는 뒤에 공백이 있을 때만 목록으로 인식(`-1점`처럼 음수가 항목으로 바뀌는 문제 방지). `⚠` 기호는 변형 선택자(U+FE0F) 유무와 관계없이 강조 메모로 인식.

## 4. 검증 결과

- Opus: 자유 변수 검사(client 함수 밖 식별자 참조 없음, 최소 DOM 스텁으로 #seed·#notice·#post 경로 실행 시 ReferenceError 0건), 실제 공지 2건 변환(큰 제목 6, 목록 22, 이어짐 2, 메모 1 / 소제목 5, 월 7, 목록 18), XSS 5종 이스케이프, 경계값 12종, ul/li 태그 균형, roster 회원 61명 바이트 동일·게스트 32명 점수와 시드 구간 전원 일치, 게스트 표 정렬·순위·검색 e2e, CSS 백틱·`${`·중괄호 균형·모바일 블록 위치, 비밀값 0건 → 수정 1건 후 **통과**.
- Fable: `node check-login.mjs` PASS(규칙 조정 후 재실행). 조정한 규칙 확인: `-1점 패배 처리`는 문단, `- 당일 사용 불가`는 목록, `⚠`·`⚠️` 모두 메모. 로컬 미리보기(사용자 크롬)에서 공지 목록(라벨+Do Hyeon 제목), 공지 상세 2건(초록 막대 큰 제목, 마름모 소제목, 초록 점 목록, 회색 이어짐 줄, 노란 메모), 시드현황 게스트 탭(회원 표와 동일한 8열, 32명, 점수순) 화면 확인.
