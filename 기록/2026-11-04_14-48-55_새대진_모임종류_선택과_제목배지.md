# 새 대진 모임종류 선택과 제목 배지 (요청 159)

## 요청

- 새 대진 만들기의 날짜·장소·시간보다 앞에 `모임종류` 버튼을 둔다.
- 버튼을 누르면 `정모`, `소정모`, `벙개`를 세로로 보여주고 하나를 반드시 선택한다.
- 변경 이후 새로 만드는 대진에 한해 제목 맨 앞에 선택한 종류를 작은 네모 배지로 표시한다.
- 기존 대진에는 종류를 추정하거나 자동으로 붙이지 않는다.

## 구현

- 운영진과 회원의 새 대진 만들기가 함께 쓰는 설정 화면에 모임종류 선택 패널을 추가했다.
- 모임종류를 선택하지 않으면 생성이 중단되고 선택 안내가 열린다.
- 모임종류는 제목 문자열에 합치지 않고 `meetingType`으로 별도 저장한다. 제목을 바꿔도 종류가 유지된다.
- 목록과 상세 제목의 첫 부분에만 작은 종류 배지를 렌더링한다. 정모는 초록, 소정모는 베이지, 벙개는 다홍 계열로 구분한다.
- 서버는 세 종류만 허용하고, 필드가 없는 기존 대진은 그대로 저장·표시한다.
- 키보드 사용자는 방향키로 종류를 순환 선택할 수 있고 선택 항목으로 초점이 이동한다.

## 검증

- 모임종류 버튼이 날짜 버튼보다 먼저 오는지, 세 항목이 세로 목록인지, 미선택 시 거부되는지 검사했다.
- 선택 결과가 새 대진 저장·상세 조회·목록 조회에 유지되는지 검사했다.
- 허용되지 않은 종류는 서버에서 거부하고, 종류가 없는 기존 대진에는 필드와 배지가 자동 추가되지 않는지 검사했다.
- 방향키 선택, 순환 탐색, 포커스 이동, roving `tabindex`를 검사했다.
- `node check-login.mjs` 전체 회귀 검사 PASS.
- Astra 최종 검토의 키보드 접근성 권고를 반영한 뒤 재검사했으며 추가 발견 사항 없음.
- 로컬 미리보기 서버는 정상 기동했으나 화면 브라우저의 로컬 연결이 시간 초과되어, 화면 확인은 배포 후 공개 주소에서 다시 진행한다.

## 배포

- 현재 GitHub main push 및 Cloudflare 자동 배포 전이다.
- 배포 후 GitHub 검사, Cloudflare Workers Build, 공개 응답과 반영 코드를 확인해 이 기록을 갱신한다.

## 핵심 명령

새 대진은 정모·소정모·벙개 중 하나를 먼저 선택하고, 선택한 모임종류는 기존 대진에 소급하지 않고 새 대진 제목 맨 앞의 작은 배지로 표시한다.
