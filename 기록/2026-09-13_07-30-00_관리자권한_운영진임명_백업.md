# 홈페이지 관리자 권한 — 운영진 임명/해제(왕관) + 백업(주간 자동·1개월 보관)

- 작업 시각: 2026-09-13 06:40 ~ 07:35 KST
- 작업 도구: Claude Code (Opus 4.8 본체 — 새 인증 계층·백업 설계·구현·테스트·브라우저 하니스 검증)
- 관련 요청: 073(관리자 권한·운영진 임명/해제), 074(백업 주간 자동·1개월 보관)
- 사용자 확인(AskUserQuestion): 관리자는 새 관리자 비밀번호(별도). 백업은 자동 주간+관리자 수동·1개월 보관.

## 1. 요청 요약

- 073: 운영진권한 버튼 아래에 '홈페이지관리자 권한' 버튼. 관리자는 운영진을 임명/해제해 왕관을 달거나 뗄 수 있다(운영진을 DB로 관리).
- 074: 관리자는 공지·대진·시드를 백업. 매주 자동 백업, 1개월 지난 백업은 순차 삭제. 관리자 수동 백업·다운로드도.

## 2. 인증 설계 (중요)

- 관리자 로그인은 운영진 로그인과 같은 방식(비밀번호 → 비밀 주소 redirect). 관리자 비밀 주소 키는 **EDITOR_KEY + ADMIN_PASSWORD에서 서버가 SHA-256으로 파생**(`admin-login.js`의 adminKeyFor). 따라서 **새로 등록할 비밀값은 ADMIN_PASSWORD 하나**뿐이고, 운영진이 EDITOR_KEY를 알아도 ADMIN_PASSWORD 없이는 관리자 주소를 만들 수 없다.
- 관리자 모드는 운영진 권한을 포함한다(admin이면 editor=EDITOR_KEY). 관리자 전용 동작(운영진 임명/해제, 백업)은 `x-kokkiri-admin` 헤더(=파생 관리자 키)로 검증.

## 3. 수행 내용과 변경 파일

- `drizzle/0010_admin_operators_backups.sql`: ranking_members에 `is_operator`(초기 운영진 6명 UPDATE), `backups` 테이블.
- `dist/server/rankings.js`: INITIAL_OPERATORS(로토·백구·구구·이코·뉴키·단우), buildInitialRankings/ensureRankingMembers가 is_operator 시드.
- `dist/server/admin-login.js`(신규): 관리자 로그인 + adminKeyFor(파생 키).
- `dist/server/boards.js`:
  - adminKey 계산, `/administrate-<adminKey>` = 관리자 모드, `/api/admin-login`.
  - `page(editor,admin)` — 관리자면 헤더 '관리자', 클라에 ADMIN 주입.
  - /api/rankings·/api/people에 is_operator 포함.
  - POST /api/operator-role(관리자, is_operator 토글).
  - createBackup(공지·대진·시드 스냅샷 + 31일 초과 삭제), /api/backups(GET 목록·POST 생성)·GET /api/backups/:id(JSON 다운로드), 모두 관리자 전용.
  - `scheduled` 핸들러(주간 자동 백업).
- `wrangler.jsonc`: `triggers.crons: ["0 0 * * 0"]`(매주 일 00:00 UTC).
- `dist/server/boards-client.js`: client(EDITOR,ADMIN). 회원 홈에 '홈페이지관리자 권한' 버튼(운영진 버튼 아래). 왕관 동적화(OPERATORS를 is_operator로 동기화). 관리자 모드 시드현황: 회원 표에 '운영진 임명/해제' 버튼, 상단 백업 패널(지금 백업·목록·다운로드).
- `dist/server/boards-style.js`: .admin-access(운영진 버튼 위), .op-toggle, .admin-panel, .backup-list/.backup-row/.backup-dl.

## 4. 검증 결과

- `node check-login.mjs` PASS. 관리자 검증: admin-login(틀림 401·맞음 200·redirect=/administrate-<파생키>), is_operator 초기값(로토 1), operator-role 토글(무헤더 403·관리자 200·임명/해제 반영), 관리자 페이지 200, 백업(무헤더 403·생성 200·목록·JSON 다운로드), scheduled 자동 백업으로 백업 증가.
- 브라우저 하니스: 관리자 모드 시드현황에 백업 패널·지금 백업·목록, 회원 행 '운영진 임명/해제'(로토=해제·시오/구름=임명), 왕관 동적(로토만). op-toggle 클릭이 x-kokkiri-admin 헤더로 {memberId,on} 호출. 회원 모드에 두 버튼(운영진권한·홈페이지관리자 권한), 관리자 다이얼로그 확인.

## 5. 사용자가 직접 해야 할 일 (중요)

- **Cloudflare 대시보드 → Workers & Pages → kokkiri → Settings → Variables and Secrets 에 `ADMIN_PASSWORD` 를 추가**(값은 사용자가 정한 관리자 비밀번호). 등록 전에는 '홈페이지관리자 권한' 로그인이 503으로 준비 중 표시된다. (값은 문서·코드에 남기지 않는다.)
- 주간 자동 백업(Cron)은 배포 시 자동 등록된다. Cloudflare 대시보드 Triggers에서 확인 가능.

## 6. Git 동기화·배포 결과

- 커밋·push 후 Cloudflare 자동 배포(마이그레이션 0010 + Cron). 해시·라이브 확인은 배포 후 기록.

## 핵심 명령

홈페이지 관리자 권한을 만들어 운영진을 임명/해제하고, 공지·대진·시드를 주간 자동·1개월 보관으로 백업한다.
