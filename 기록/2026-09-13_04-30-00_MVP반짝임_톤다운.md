# MVP 반짝임(shine) 톤다운 — 흰색 혼합 제거로 가독성 개선

- 작업 시각: 2026-09-13 04:20 ~ 04:35 KST
- 작업 도구: Claude Code (Fable 직접 처리 — 단일 파일 CSS 수정, 브라우저 프리뷰로 확인)
- 관련 요청: 067

## 1. 요청 요약

- MVP 반짝임 표시가 흰색과 섞여 눈부시고 가독성이 떨어진다. 톤다운된 느낌의 반짝임으로 바꿔달라.

## 2. 원인과 조치

- `.mvp-title`의 그라데이션이 `#d8ffe9`(거의 흰색인 연초록)를 하이라이트로 써서, 반짝임이 그 위상에 오면 글자가 흰 배경/연초록 배너(#f2fbf5) 위에서 사라지듯 밝아져 눈이 부시고 안 읽혔다.
- 조치(`dist/server/boards-style.js`): 하이라이트를 가독성 있는 톤다운 초록으로 교체.
  - 기존: `linear-gradient(100deg,#0a8a44 0%,#37d67a 22%,#d8ffe9 42%,#37d67a 60%,#0a8a44 100%)`, `mvpShine 3.4s`.
  - 변경: `linear-gradient(100deg,#0a7a3c 0%,#1f9e54 30%,#57c489 48%,#1f9e54 66%,#0a7a3c 100%)`, `mvpShine 4.2s`(조금 더 느리고 은은하게).
  - 하이라이트 최고 밝기가 `#57c489`(중간 초록)라 어떤 위상에서도 흰 배경·연초록 배너 위에서 글자가 읽힌다.
- 적용 범위: `.mvp-title`은 대진표 상세 제목(h1)과 홈 MVP 배너 이름 모두에 쓰이므로 한 규칙 수정으로 둘 다 반영.

## 3. 검증

- scratchpad/mvp-preview.html로 옛/새를 흰 배경·연초록 배너에 나란히 렌더해 비교(브라우저 스크린샷): 기존은 가운데가 흰색으로 바래 안 보이고, 변경은 전체가 또렷한 초록으로 유지되며 은은한 광택만 남음.

## 4. 미완료 사항과 다음 단계

- 같은 시점 사용자 추가 요청(별도 진행): 게스트도 점수 변동 대상(정산 반영), 게스트→회원 이관 버튼. 정산 규칙 변경이라 범위 확인 후 진행.

## 5. Git 동기화·배포 결과

- 커밋·push 후 Cloudflare 자동 배포(해시·라이브 확인은 배포 후 기록).

## 핵심 명령

MVP 반짝임의 흰색 혼합을 없애 톤다운된 초록 광택으로 가독성을 높인다.
