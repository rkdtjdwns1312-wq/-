# 마감 확인 문구 자연화, 마감 취소(정산 되돌리기), 목록 마감 표시

- 작업 시각: 2026-09-12 15:00 ~ 15:20 KST
- 작업 도구: 아래 본문은 원본 1의 Claude Code(Fable 본체·Opus 검증) 서술을 보존한다. 원본 2의 Codex 구현·Claude Code(Opus 4.8) 검증 서술은 통합 절에 함께 남긴다.
- 관련 요청: 053, 054. 기록 통합: 057.

## 1. 요청 번호와 요청 요약

- 요청 053: (1) '대진 종료' 확인창 문구를 "마감할까요?"로 자연스럽게. (2) 잘못된 기록 반영 대비, 마감된 대진을 되돌리는 '마감 취소' 버튼·기능. (3) 대진표 목록에서 마감된 대진은 제목 오른쪽에 작은 회색 "마감" 표시.

## 2. 계획 (Fable/본체)

- 정산 되돌리기: settleSchedule이 남기는 ranking_events(회원별 델타)를 역산해 points/attendance/wins/losses 원복, 순위·시드 재계산, settledAt·MVP 제거, 제목 복원, ranking_settlements·events 삭제.
- 안전장치: 가장 최근에 마감한 대진표만 취소 가능(여러 정산의 복잡한 상호작용·주간 초기화 문제 회피). 점수는 누적이라 역산이 정확; 출석/승/패는 주간 초기화가 있어 max(0,..)로 클램프.
- 제목 복원 위해 settle 시 preTitle(원 제목) 저장.
- 목록 마감 표시: 목록 쿼리에 settledAt 추가, 마감된 schedule에 회색 태그.
- 문구: '대진 종료'→'대진 마감'으로 통일, 확인창 "마감할까요?".

## 3. 수행 내용과 변경 파일 (Fable 직접 처리)

- `dist/server/boards.js`: settle nextPayload에 `preTitle:post.title`. 새 `unsettleSchedule(db,id)`(가장 최근 마감만; 델타 역산·클램프; settledAt null·mvp []·title 복원·preTitle 제거; settlements·events 삭제; 순위/시드 재계산·previous_rank=신규rank). 새 라우트 `POST /api/posts/:id/unsettle`(운영진 전용). 목록 SELECT에 `json_extract(payload,'$.settledAt') AS settledAt`.
- `dist/server/boards-client.js`: 확인창 "정말 이 대진을 마감할까요? … (마감 후에도 되돌릴 수 있어요.)". '대진 종료'→'대진 마감'(버튼·안내·편집 안내). settled+운영진 상세에 '마감 취소'(.danger) 버튼+핸들러(확인→/unsettle→재렌더). 목록 항목에 settled면 `<span class="settled-tag">마감</span>`.
- `dist/server/boards-style.js`: `.settled-tag`(회색 작은 pill).
- `check-login.mjs`: 마감 취소 검증(비운영진 403, 운영진 200, 시오·구구 점수 정확히 -2 원복, settledAt null, mvp [], 제목 MVP 아님, 재취소 400).

## 4. 당시 검증 결과 (원본 1: 본체 + Opus + 테스트 + 브라우저 e2e)

- `node check-login.mjs` PASS.
- 브라우저 e2e(운영진): 4경기 기록→'대진 마감' 버튼→확인창 "…마감할까요?…"(예/아니오)→예→마감(settledAt, 마감취소 버튼, 수정 숨김). 목록에 회색 "마감" 태그(마감본만). '마감 취소'→확인→원복: 로토 107→104·1/3/1→0, 백구 89→88·1/2/2→0, settledAt null, 수정 버튼 복귀. 정확히 역산됨.
- Opus 검증: **SHIP**. 7개 항목 모두 PASS. 점수는 모든 시나리오(설정→마감취소 즉시, 주간 초기화 사이, LIFO 연쇄 포함)에서 정확 역산, 출석/승/패는 max(0,..)로 음수 손상 없음(초기화된 기간엔 0이 의미상 정답). 라우트 충돌 없음, 이중 취소 400 무변경, /api/mvp·목록·updatedDate 일관. 비차단 제안(동시각 타이 정렬)을 반영해 unsettle·mvp 쿼리에 `,rowid DESC` 추가.

## 5. 최종 점검 (Fable/본체)

- 마감 취소는 가장 최근 마감만 가능(안내 문구로 알림). 점수는 정확 역산, 주간 출석/승/패는 클램프. 되돌린 뒤 결과는 유지되어 수정·재마감 가능.
