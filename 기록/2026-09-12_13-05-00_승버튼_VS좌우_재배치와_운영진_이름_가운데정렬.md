# 승 버튼 VS 좌우 재배치와 운영진 이름 가운데 정렬(왕관 분리)

- 작업 도구: Claude Code (Fable 본체 직접 처리 — 소규모 UI/CSS, 테스트·로컬 화면·DOM 측정 확인)
- 관련 요청: 042 (041 후속 미세조정 포함)

## 1. 요청 번호와 요청 요약

- 요청 042-a(041 후속): 승 버튼이 각 팀 두 사람 이름의 세로 중앙 높이에 오면서 VS 알파벳의 왼쪽·오른쪽에 배치되어야 하는데 정렬이 어긋난다. 수정.
- 요청 042-b: 운영진 이름을 가운데 정렬할 때 왕관 이미지까지 함께 잡혀 이름이 중앙에서 밀린다. 이름만 가운데 정렬하고 왕관은 옆에 따라붙게.

## 2. 계획 (Fable/본체)

- 041에서 승 버튼을 팀 박스 안 아래에 넣었더니 팀 박스 안쪽에 붙어 정렬이 어긋나 보였다. → 승 버튼을 팀 박스 밖으로 빼고, VS를 감싸는 가운데 클러스터(`.vs-cluster`: 승 · VS · 승)로 이동해 VS 좌우에 배치. `.teams`가 세로 중앙 정렬이므로 자연히 두 이름의 세로 중앙 높이에 온다.
- 왕관: `.player`(대진 화면 이름 span)를 relative·inline-block으로, 그 안의 `.crown`을 absolute(left:100%)로 흐름에서 빼서 이름 폭에 왕관이 포함되지 않게 → 이름만 가운데 정렬, 왕관은 오른쪽에 따라붙음. 시드표·참가자 선택의 왕관은 `.player` 밖이라 영향 없음.

## 3. 수행 내용과 변경 파일 (Fable 직접 처리)

- `dist/server/boards-client.js`: scheduleHTML에서 승 버튼(winBtn)을 team-wrap 밖으로 이동. 채점 라운드는 `mid='<div class="vs-cluster">'+승a+VS+승b+'</div>'`, 랜덤은 VS만. team-wrap은 이름만 담음.
- `dist/server/boards-style.js`: 041의 팀박스-내부 버튼 CSS 제거, `.vs-cluster`(flex row, 가운데)·`.win-pick`(38px 원형) 추가. `.player{position:relative;display:inline-block}`·`.player .crown{position:absolute;left:100%;top:50%;transform:translateY(-50%);margin-left:2px}` 추가.
