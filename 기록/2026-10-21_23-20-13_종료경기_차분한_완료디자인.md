# 요청 130 — 종료 경기의 차분한 완료 디자인

## 제안 및 범위

- 대기 경기는 흰 배경, 진행 경기는 초록 테두리/그림자, 종료 경기는 연회색 배경과 중립색 종료 배지로 구분한다.
- 이름·점수 가독성을 떨어뜨리는 전체 opacity나 blur를 쓰지 않는다. 승리 결과와 기존 결과 수정 기능은 유지한다.
- 실제로 버튼을 비활성화하거나 저장·정산 규칙을 변경하지 않는다. 운영 DB 시험 변경 없음.
- 앞선 요청129의 18deb8a는 공개 HTTP 200·중립 기본 테두리 코드·GitHub/Cloudflare success 확인.

## 작업 및 검증

- GPT-6 Luna CSS/회귀 검사 완료, 본체 브라우저/문서 검증 완료, GPT-6 Astra 최종 검토 Clean. `node check-login.mjs` 전체 PASS, 진행 UI 전용 검사 PASS.
- 변경 파일: `dist/server/boards-style.js`, `check-progress-ui.mjs`. 종료 카드 #f2f4f3, 테두리 #d7ddda, 종료 배지/코트 라벨 중립 회색, 비승리 팀 회색. 승리팀 초록색 유지.
- 컴퓨터 사용 스킬로 로컬 가상 DB에서 진행→승리→종료 확인: 종료 카드 회색/그림자 없음, 옆 진행 카드는 흰색/초록 테두리·그림자. 전체 불투명도 1로 읽기 쉬운 이름 유지. 종료 상태에서 승리팀 변경 및 새로고침 후 결과/디자인 유지 확인. [검증 화면](130_종료경기_완료디자인.png).
- 본체가 승인된 네트워크 pull로 최신 확인. Luna의 별도 pull은 DNS 제한으로 실패했으나 최신 동일 작업 트리에서 수정했다. 운영 DB 변경 없음.
- 구현·검증 완료, 공개 배포 확인 전.

## 핵심 명령

종료 경기는 차분한 연회색 완료 디자인으로 구분하되 가독성·승리 결과·수정 기능은 보존한다.
