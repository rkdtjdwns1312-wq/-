# 시드현황 누적출석과 참석 날짜 (요청 157)

- 사용자 요청: 시드현황의 승·패 오른쪽에 `누적출석`을 추가하고, 횟수를 누르면 참석 날짜를 세로로 보여준다.
- 누적출석은 저장된 점수 열을 복사하지 않고 과거 대진표에서 실제 경기 조에 편성된 날짜를 다시 계산한다.
- 같은 날짜에 대진표가 여러 개여도 회원별 하루 1회만 센다.
- 결석 처리된 회원, 명단에만 있고 어느 경기에도 편성되지 않은 사람, 현재 회원이 아닌 게스트는 제외한다.
- 회원 이름 변경 이력과 게스트에서 회원으로 승격된 이력을 연결한다. 이름이 여러 회원과 겹쳐 확정할 수 없는 옛 기록은 잘못 합산하지 않는다.
- 횟수 버튼을 누르면 최근 참석일 먼저 `YYYY년 M월 D일` 형식으로 세로 목록을 표시한다.

## 검증과 배포

- 직접 ID, 옛 이름, 승격 전 게스트 ID·이름, 결석, 대기만 한 사람, 같은 날 중복 대진, 날짜 없는 옛 대진을 검사했다.
- 화면 열·버튼·최근 날짜 우선 세로 목록 검사를 `check-login.mjs` 전체 회귀 검사에 통합했고 모든 검사가 PASS했다.
- 기능 커밋 `bcdceb7`을 `origin/main`에 올렸다.
- GitHub `test`와 Cloudflare `Workers Builds: kokkiri`가 모두 성공했다.
- 공개 홈 HTTP 200과 `attendance-history-open` 코드 반영을 확인했다.
- 로컬 미리보기 브라우저는 localhost에 연결되지 않아 실제 화면 자동 캡처는 생략했으며, 운영 데이터의 대진·점수·출석은 변경하지 않았다.
