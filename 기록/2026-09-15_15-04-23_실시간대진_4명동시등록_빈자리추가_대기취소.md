# 실시간대진 4명 동시 등록·빈자리 추가·대기 취소

- 일시: 2026-09-15 15:04 KST
- 요청 번호: 099
- 작업 모델: Codex(Astra)
- 대상: Cloudflare Workers 기반 콕끼리 홈페이지 실시간대진

## 요청

- `실시간대진 들어가기`에서 이름을 한 명씩이 아니라 1~4명까지 한 번에 등록한다.
- 대기 중 이름 옆 작은 원형 X로 해당 사람을 빼고, 빈자리의 +로 다시 이름을 넣는다.
- 대기 대진 오른쪽에 `대기 취소`를 두고 `대기 취소하시겠습니까?` 예/아니오 확인 후 처리한다.

## 반영 내용

- 참가 창을 이름 입력 4칸으로 변경했다. 빈칸은 무시하므로 1~4명 모두 한 번에 등록할 수 있다.
- 서버 `join`이 `names` 배열을 처리하도록 확장하고 기존 `name` 요청도 호환했다.
- 묶음 내부 중복, 현재 코트 중복, 대기열 중복, 빈자리 부족을 저장 전에 검사하여 일부만 들어가는 상태가 생기지 않도록 했다.
- 현재 코트와 대기열의 대기 상태에서 이름별 작은 X와 빈자리별 작은 +를 표시했다.
- + 입력은 선택한 코트·대기 그룹·자리 번호를 서버에 전달하여 정확히 그 빈칸만 채운다.
- 현재 대기 코트 및 각 대기 그룹에 `대기 취소`를 표시하고, 사용자 확인창에서 `예`인 경우에만 전체 대기를 비우도록 했다.
- 기존 version 기반 동시성 보호를 모든 새 동작에 유지했다.
- 시드·점수·출석·정모 대진 및 실제 공개 운영 데이터는 변경하지 않았다.
