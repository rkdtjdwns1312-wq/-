# 콕 재고 관리 (요청 156)

- 사용자 요청: 회계장부에서 선납자 명단과 같은 버튼 영역에 `콕 재고 관리`를 추가하고, 날짜·콕 변동 개수·누계를 세로로 확인할 수 있게 한다.
- 운영진은 날짜와 입고·사용 변동 수량을 입력한다. 누계는 날짜순 변동을 합산해 자동 계산한다.
- 회원은 기록을 조회할 수 있지만 수정은 운영진만 가능하다.
- 저장 데이터는 별도 D1 테이블과 버전 이력에 보관하며 기존 회계장부·회원·대진 데이터와 분리했다.
- 중복 저장 재시도, 동시 수정 충돌, 잘못된 날짜·0개 변동·중복 ID·대량 입력, 권한과 감사 이력을 검사했다.

## 검증과 배포

- 새 서버·화면 검사를 `check-login.mjs` 전체 회귀 검사에 통합했고 모든 검사가 PASS했다.
- 기능 커밋 `bcdceb7`을 `origin/main`에 올렸다.
- GitHub `test`와 Cloudflare `Workers Builds: kokkiri`가 모두 성공했다.
- 공개 홈 HTTP 200, `/api/shuttle-inventory` 코드와 콕 재고 관리 화면 코드 반영을 확인했다.
- 실제 운영 재고 수량은 임의로 입력하지 않았다.
