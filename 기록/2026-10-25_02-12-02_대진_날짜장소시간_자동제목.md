# 요청 136 — 대진 날짜·장소·시작시간 자동 제목

## 요청·설계

- 새 대진 만들기에서 수기 제목 대신 `대진 날짜와 장소` 아래 날짜 선택하기 / 장소 입력하기 / 시작시간 버튼을 둔다.
- 날짜 버튼은 한국 시간 현재 월의 달력을 열고 이전/다음 달 화살표와 날짜 직접 선택을 지원한다. 장소 버튼은 직접 입력칸, 시작시간은 24시간제 시(00~23)·분(00~59) 선택칸을 연다.
- 날짜/장소/시간을 모두 지정하면 `N월 N일(요일) 장소 HH:mm` 제목 미리보기와 생성 제목을 사용한다. 공백/요일은 자동 계산한다. 기존 저장 대진의 참가자·코트 재편성은 기존 제목 입력을 유지하여 과거 제목을 임의 변경하지 않는다.
- DB 구조/점수/정산은 변경하지 않는다. 생성 제목의 `(토)`는 기존 토요일 출석 규칙과 호환된다.
- 작업 전 clean, git pull 최신03f1a96. 본체 UI/통합·회귀검사, GPT-6 Luna CSS, Astra 최종 점검. 5.6 Luna는 현재 제공되지 않아6 Luna 사용.

## 검증·배포

- `check-login.mjs` 전체 PASS. 실제 직렬화 팩터리의 현재월/KST 경계·윤년·연말 이동·날짜/장소/시간 검증, 00:00/23:59, Esc와 입력 보존을 검사했다.
- 로컬 브라우저에서 달력 전후 월 이동→10월25일 선택→중앙체육관→18:30→대진 생성/저장 후 제목을 확인했다. 320/390px 달력 가로 넘침 없음, 320px 월 표시 줄바꿈도 보완했다. 사진: `2026-10-25_대진날짜_모바일_달력.png`.
- GPT-6 Luna 스타일/팩터리 검사, GPT-6 Astra 전체 최종 검토 PASS. 공개 배포 확인 대기. 실제 운영 대진으로 생성/정산 시험은 하지 않는다.

## 핵심 명령

날짜·장소·24시간제 시작시간을 선택해 새 대진 제목을 자동으로 만든다.
