# 불참(무효 경기)·코트 추가(라운드 경기 수 가변) — 서버·화면

- 작업 시각: 2026-09-13 00:50 ~ 01:15 KST
- 작업 도구: Claude Code (Opus 4.8 본체 직접 구현·테스트)
- 관련 요청: 061(불참 무효), 062(코트 추가)

## 1. 요청 요약

- 061: 참가자를 불참으로 지정하면 그 사람이 들어간 경기는 무효(출석·승·패 미반영). 불참자 본인은 출석도 0.
- 062: 라운드에 경기(코트)를 추가할 수 있게(대체 경기로 경기 수가 늘어난 경우). 한 라운드에 같은 사람이 두 경기를 뛸 수 있음.

## 2. 수행 내용과 변경 파일 (본체)

- `dist/server/boards.js`:
  - validate(): 라운드 경기 수 고정(=코트) 검사 제거 → 1~100 가변 허용, 각 경기 4명 중복 없음만 확인, 라운드 내 중복 배치 허용(대체 경기). `absent`(불참 명단) 저장. 미기록 문구 '코트'→'대진'.
  - settleSchedule(): `absentSet`·`isVoid(match)` 추가. 완료 판정·승패 합산·MVP에서 무효 경기 제외. 출석은 불참자 제외한 회원만 +1.
  - `/api/posts/:id/result`: 불참자 포함 경기면 400.
- `dist/server/boards-client.js`: scheduleHTML에 `isVoid` — 무효 경기는 승 버튼 없이 '불참자 있어 무효' 안내, `void-match`. roundDone·allScoredDone·incompleteRounds에서 무효 경기 제외.
- `dist/server/boards-style.js`: `.void-note`(회색), `.void-match{opacity:.7}`.
- `check-login.mjs`: 코트추가(한 라운드 2경기·중복 배치, 시오 +3·구구/구름 +1·백구 -1)·불참(백구 불참→무효·출석0, 무효 /result 400, 호잇/뚜기 +2, 시오 출석만 +1) 검증.

## 3. 검증 결과

- `node check-login.mjs` PASS(코트추가·불참 델타 정확).

## 4. 미완료·다음 단계

- 운영진 편집 UI(참가자 불참 지정 토글, 라운드 코트 추가 ＋ 버튼)는 이어서 구현.
- 라이브 게시판에 정모 대진표를 넣으려면 운영진 키(비밀값)가 필요해 API로는 불가 → 대진표·게스트(아식스/제냐/허니)는 마이그레이션으로 DB에 직접 삽입(옛 0004 이관과 동일 방식), 마감 전 상태로 게시.

## 핵심 명령

불참자 경기 무효 처리와 라운드 코트 추가(가변 경기 수)를 지원하고, 화면에 무효 경기를 표시한다.
