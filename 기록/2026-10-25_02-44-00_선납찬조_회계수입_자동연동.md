# 요청145 — 선납·찬조 회계 수입 자동 연동

## 요청·사용자 확인

- 현재 별도관리이던 선납/찬조명단 금액을 장부 총수입·누계에 자동반영한다. 명단 추가/수정/삭제를 장부에 연결한다.
- 사용자 확인: 아직 해당 금액을 장부 수입에 따로 입력하지 않았으므로 기존 명단도 모두 자동반영한다.
- 설계: 명단DB를 원본으로 장부조회시 자동수입 항목을 구성한다. 수동장부에복사하지않아재조회/저장시중복없음. 자동항목은장부에서직접수정불가, 해당명단에서수정. 수동거래와시작잔액/점수/권한은유지.
- 서버/API/회귀/Astra최종검토는GPT-6 Astra, 본체장부UI/문서/실화면, 경량작업은필요시Luna. 실제 운영명단·장부를 시험수정하지않는다.

## 검증·배포

- GPT-6 Astra 백엔드 구현 및 별도 Astra 최종 리뷰: 수정 필요 결함 없음. 기존 수동중복 위험은 사용자의 미입력 확인으로 해소.
- 전체 check-login PASS: 기존 명단, 추가/수정/삭제, 재시도, CAS, 손상원본 fail-closed, 권한, 1,500행 안전정수, UI 수동/자동 분리.
- 실제 로컬 브라우저: 선납30,000원 저장 → 수동장부 저장(복제없음) → 명단45,000원 수정 → 장부총수입/누계45,000원 확인. 자동행 편집대신 명단에서수정 버튼 확인.
- 실제 운영데이터를 시험변경하지 않았다. 코드 f7aebfd GitHub push 및 Cloudflare 배포·CI success. 공개 회원 화면에서 기존 선납20,000+찬조30,000=수입50,000원/지출510,500원/누계-460,500원과 자동연동2행 확인(2026-10-25 02:49 KST).
