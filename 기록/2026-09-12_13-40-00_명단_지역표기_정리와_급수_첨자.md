# 명단 (서울)·(부재) 정리, 겹치는 이름 지역 회색 표기, 급수 +/- 위첨자

- 작업 시각: 2026-09-12 13:30 ~ 13:45 KST
- 작업 도구: Claude Code (Fable 본체 직접 처리 — 데이터·표시 수정, 테스트·로컬 DOM·화면 확인)
- 관련 요청: 045, 046

## 1. 요청 번호와 요청 요약

- 요청 045: 회원·게스트 명단에서 (서울)·(부재) 표기 제거. 단, 이름이 겹칠 때는 지역명을 남기되 연한 작은 회색 글씨로 표기.
- 요청 046: 급수의 + 표시를 오른쪽 상단 첨자(작은 크기)로.

## 2. 계획 (Fable/본체)

- 명단의 (부재)·(서울) 이름을 조사해 겹침 여부 판정: 겹치지 않는 7개는 제거, 겹치는 2개는 지역 표기 유지(회색 렌더).
  - 제거(겹침 없음): 덕자(부재)→덕자[회원], 우민(부재)→우민[회원], 민석·민수·호구·우주·윤후(서울)→기본 이름[게스트].
  - 유지(겹침): 철(서울)[게스트]는 회원 '철'과 겹침, 선호(서울)[게스트]는 게스트 '선호'와 겹침 → 지역 표기 유지.
- 회원(덕자·우민)은 D1 ranking_members에도 저장돼 있어 마이그레이션 0005로 기존 행 UPDATE. 게스트는 roster.js만 고치면 됨(랭킹 테이블 미저장).
- 표시: 클라이언트에 `nameHTML`(이름 끝 "(지역)"을 회색 작은 `.region`으로, 단 앞에 공백 없는 경우만 → nameOf의 " (게스트)" 접미사는 제외)·`seedHTML`(끝의 +/-를 `<sup class="seed-mod">`로) 헬퍼 추가 후 대진 이름·참가자 선택·시드 회원표·시드 게스트표에 적용.

## 3. 수행 내용과 변경 파일 (Fable 직접 처리)

- `dist/server/roster.js`: 덕자·우민(회원) 및 민석·민수·호구·우주·윤후(게스트) 이름 정리. 철(서울)·선호(서울)은 유지.
- `dist/server/rankings.js`: initialRankingRows의 덕자(부재)→덕자, 우민(부재)→우민.
- `dist/server/drizzle/0005_clean_member_names.sql`: `UPDATE ranking_members SET name=... WHERE member_id IN (member-35, member-42)`. wrangler 마이그레이션으로 배포 시 기존 라이브 행 정리.
- `dist/server/boards-client.js`: `nameHTML`·`seedHTML` 헬퍼 추가. scheduleHTML player, openPicker 목록, seeds 회원표·게스트표에 적용. (nameHTML 정규식은 한 글자 이름 '철'도 매칭되도록 `(.*[^\s])` 사용.)
- `dist/server/boards-style.js`: `.region`(0.72em, 회색 #9fb0a6)·`.seed-mod`(0.7em, vertical-align:super) 추가.
- `check-login.mjs`: 마이그레이션 목록에 0005 추가. 정리·유지 이름 검증 추가(회원 랭킹에 (서울)/(부재) 없음, 덕자·우민 존재, 민석 등 정리, 철(서울)·선호(서울) 유지, 선호 2명 존재).

## 4. 검증 결과 (본체 검토 + 테스트 + DOM/화면)

- `node check-login.mjs` PASS.
- 로컬 DOM(시드현황): 회원표 덕자/우민 정리, region 0개, 급수 첨자 20개. 게스트표 철→"철"+회색"서울", 선호(서울)→"선호"+회색"서울", region 2개, 급수 첨자 13개, 민석 등 정리.
- 화면: 게스트표 급수가 A⁺ 형태(+가 오른쪽 위 작은 첨자)로 표시.
- nameHTML 정규식 버그(한 글자 이름 '철' 미매칭 `(.+[^\s])`) 발견 → `(.*[^\s])`로 수정 후 철·선호 모두 정상.

## 5. 최종 점검 (Fable/본체)

- 045: 겹치지 않는 표기는 제거, 겹치는 철·선호만 회색 지역 표기 유지. nameOf의 회원/게스트 접미사는 회색 처리되지 않음(공백 규칙). 대진에 두 사람이 함께 들어가도 이름 유일성 유지(철(서울)≠철, 선호(서울)≠선호).
- 046: 시드·참가자 선택의 급수 +/-가 위첨자. (사용자는 +만 언급했으나 -도 동일하게 첨자 처리해 E- 등 일관성 확보 — 필요 시 조정 가능.)
- 라이브 회원 시드표는 배포 시 마이그레이션 0005가 기존 덕자(부재)/우민(부재) 행을 정리한다(빌드가 `wrangler d1 migrations apply` 실행).
