## 재현·보완한 서버 결함

- 서로 다른 대진을 동시에 마감하면 같은 이전 점수로 계산하여 먼저 반영된 점수를 덮어쓰는 결함 재현(기존 응답 200, 기대 409). `0014_roster_write_revision.sql`과 `roster-write.js`로 공용 변경 버전 검사 도입. 마감/취소/회원 추가·수정·숨김·이관을 보호한다. 기존 점수 데이터는 마이그레이션에서 바꾸지 않는다.
- 회원 수정·변경 이력·순위 재배치가 따로 저장되던 문제를 동일 트랜잭션에 묶음. 이력 저장 실패를 강제로 일으켜 점수/순위/버전까지 원복되는 것을 확인했다. 명단 숨김 이력도 추가했다.
- 마감/취소가 회원·게스트 edit_version도 올려 이전에 열어 둔 점수 수정창의 덮어쓰기를 막는다. 마감 취소 API는 새 클라이언트의 표시 버전을 확인하고 기존 버전 미전송 호출은 호환한다.
- 삭제 직전 마감된 대진이 삭제될 수 있던 경쟁 상황을 게시글 version 조건으로 차단.
- 참가 ID 배열의 잘못된 항목을 필터링해 뒤 사람과 이름이 엇갈릴 수 있어 길이/타입/중복을 검증한다. 회원으로 이관 후 이름까지 바뀐 게스트도 과거 참가 ID로 정산한다. 명시적 미등록 ID를 동명이인의 이름으로 대체 정산하지 않는다(옛 ID 없는 명단만 이름 매칭).
- null/배열 등 잘못된 입력은 400, DB 장애의 회원 목록은 JSON 503으로 반환. 승패 키의 00-0 같은 비정규 표기를 거절한다. 숨긴 회원 이름과의 충돌도 친절한 409로 처리하고 자기 이관 원본 게스트는 중복에서 제외한다.
- 백업의 7개 데이터 묶음을 한 번의 읽기 트랜잭션에서 가져와 마감 전후 혼합을 방지한다.

- 기준: [Cloudflare D1 한도](https://developers.cloudflare.com/d1/platform/limits/)의 무료 요청당 50쿼리, [D1 batch](https://developers.cloudflare.com/d1/worker-api/d1-database/)의 전체 롤백·순서 보장. 유료 전환이나 실제 운영 부하 시험을 하지 않았다.
- Terra 생성기 검토: 소수 코트 수가 2명 경기와 TypeError를 만들 수 있는 내부 경계값을 검증으로 차단. 시드 고정 160가지 조합과 기존 300라운드 검사로 늦참·휴식·4인 구성·팀 평균 균형·수기 중복 출전 규칙을 유지했다.
