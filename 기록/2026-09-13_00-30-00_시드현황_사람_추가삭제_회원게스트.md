# 시드현황 사람 추가/삭제(회원·게스트) — 대진 만들기 선택·수 반영

- 작업 시각: 2026-09-13 00:10 ~ 00:35 KST
- 작업 도구: Claude Code (Opus 4.8 본체 서버 직접 구현·검증, Sonnet 서브에이전트 1개 UI 구현, Opus 서브에이전트 1개 검증)
- 관련 요청: 060 (임시 게스트가 삭제 안 되는 문제 → 시드현황에서 제대로 추가/삭제하는 방식으로 전환)

## 1. 요청 번호와 요청 요약

- 요청 060: 대진 만들기 임시 게스트는 삭제 버튼이 없어 계속 남는다. 대신 시드현황에 운영진용 "수정하기" → 추가하기/삭제하기(체크박스)로 회원·게스트를 각각 추가·삭제. 닉네임+시드점수+회원/게스트 선택으로 추가. 추가·삭제가 대진 만들기의 선택 가능한 사람과 회원·게스트 수에 반영.

## 2. 계획 (본체)

- 회원은 이미 ranking_members(DB). `hidden` 컬럼 추가로 삭제=숨김(정산 이력 FK 보존). 게스트는 정적(roster.js)이었으나 추가/삭제 위해 `guests` 테이블로 이관(코드가 정적 32명을 INSERT OR IGNORE 시드).
- /api/people·/api/rankings는 hidden=0만 반환. 추가/삭제 엔드포인트(운영진 전용). 회원 추가 시 hidden=0만 재정렬해 순위 빈칸 방지. 클라이언트는 추가/삭제 후 people 캐시 무효화(=[]) → 대진 만들기 재조회.

## 3. 수행 내용과 변경 파일

- `drizzle/0006_people_manage.sql`(본체): `ALTER TABLE ranking_members ADD COLUMN hidden ...`, `CREATE TABLE guests(...)`.
- `dist/server/boards.js`(본체): `appGuests`·`ensureGuests`, /api/people GET(회원=ranking_members hidden0, 게스트=guests hidden0·seedForPoints), /api/rankings hidden0, POST /api/people(회원/게스트 추가·이름중복 409·점수 0~1000·회원 추가 후 재정렬), POST /api/people/hide(선택 숨김). settle·unsettle의 회원 조회에 `WHERE hidden=0`.
- `dist/server/boards-client.js`(Sonnet): seeds() 재작성 — 운영진 "수정하기" 토글, 편집 모드 체크박스+추가하기+선택 삭제, 추가 다이얼로그(닉네임·시드점수·회원/게스트 aria-pressed), refresh()로 people 캐시 무효화.
- `dist/server/boards-style.js`(Sonnet): `.seed-cb` 스타일.
- `check-login.mjs`(본체): 마이그레이션 0006 추가, 사람 추가/삭제 검증(비운영진 403, 회원 추가 62명·seed D+, 이름중복 409, 게스트 추가 33명·seed E+, 숨김 후 61/32 복원).

## 4. 검증 결과 (테스트 + 브라우저 e2e + Opus)

- `node check-login.mjs` PASS.
- 브라우저 e2e(운영진 시드현황): 수정하기→편집 모드(체크박스·추가하기·선택 삭제). 게스트 추가(테스트게스트A 50점→seed D+): /api/people 게스트 33, 시드표 표시. 체크 삭제: /api/people에서 제거, 게스트 32 복원. 회원 추가(테스트회원A 95점): /api/rankings 62명, 순위 1..62 빈칸 없음, 추가 회원 9위·B+.
- Opus 검증: 결함 1건 발견·수정 — 삭제(/api/people/hide)가 남은 회원 순위를 재계산하지 않아 순위에 빈칸이 생김(예: 삭제 후 33번 없음). 수정: 숨김 batch 뒤에 hidden=0만 orderRankingRows로 재정렬(추가 경로와 동일). 테스트에 삭제 후 순위 1..N 연속 단언 추가. 나머지 6개 항목 PASS(마이그레이션·이름중복 409·게스트 시드·정산 불변·FK 보존 등).

## 5. 최종 점검 (본체)

- 추가/삭제가 시드현황·/api/people·/api/rankings·대진 만들기(캐시 무효화로 다음 조회 시)에 반영. 삭제는 숨김이라 정산 이력 보존, 필요 시 복구 가능(현재 UI엔 복구 없음).
