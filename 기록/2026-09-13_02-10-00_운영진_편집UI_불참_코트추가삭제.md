# 운영진 대진 편집 UI — 불참자 지정 토글 · 코트 추가(＋) · 코트 삭제(✕)

- 작업 시각: 2026-09-13 01:50 ~ 02:20 KST
- 작업 도구: Claude Code (Opus 4.8 본체 — 계획·구현·브라우저 검증). 단일 기능·정밀 스펙이라 본체가 직접 구현하고 로컬 브라우저 하니스로 실제 조작 검증.
- 관련 요청: 064 (061·062의 편집 UI 마무리)

## 1. 요청 요약

- 061(불참 무효 경기)·062(코트 추가) 서버·데이터 모델은 완료·배포됐으나 운영진 편집 UI가 없었다. 대진 수정 화면에서 (1) 참가자를 불참으로 지정하는 토글, (2) 라운드에 코트(경기)를 추가하는 ＋ 버튼, (3) 코트를 삭제하는 ✕ 버튼을 만든다.

## 2. 계획 (Fable/본체)

- 편집은 `editSchedule(d)` → `#editMatches`에 `scheduleHTML(draft,true,true)`를 그리고, 클릭(승 버튼)·변경(선수 드롭다운)을 이벤트 위임으로 처리하는 기존 패턴을 그대로 확장한다.
- 서버는 이미 `absent[]` 저장, 라운드 경기 수 1~100 가변, 라운드 내 중복 배치, 정산/‘/result’ 무효 제외를 지원(061·062). 추가 서버 변경 없음.

## 3. 수행 내용과 변경 파일 (본체 직접 구현)

- `dist/server/boards-client.js`
  - `scheduleHTML`(편집 모드 전용):
    - 상단에 '불참자 지정' 패널 추가 — `d.names`를 칩 버튼(`.absent-toggle`, `data-absent-name`, `aria-pressed`)으로 나열, `d.absent` 포함 시 `on`.
    - 각 경기 `.court`에 코트 삭제 버튼(`.del-court`, `data-del-court="ri-mi"`, ✕).
    - 각 라운드 `.matches` 뒤에 코트 추가 버튼(`.add-court`, `data-add-court="ri"`, ＋).
  - `editSchedule`: `draft.absent=Array.isArray(draft.absent)?draft.absent:[];` 초기화. `#editMatches` onclick에 세 분기 추가(승 버튼 분기보다 앞):
    - 불참 토글: `draft.absent`에서 이름 추가/삭제 후 재렌더 → `isVoid`가 즉시 무효 처리.
    - 코트 추가: `r.rest`→`draft.names` 순으로 서로 다른 4명을 골라 `r.g.push`, `r.rest` 재계산. 4명 미만이면 알림.
    - 코트 삭제: `r.g.length<=1`이면 알림(최소 1개). confirm 후 `r.g.splice(mi,1)`, **결과 키 재인덱싱**(같은 라운드에서 `mi` 제거, `mi`보다 큰 인덱스는 1씩 당김), `r.rest` 재계산.
- `dist/server/boards-style.js`: `.absent-panel/.absent-title/.absent-hint/.absent-chips/.absent-toggle(.on)`, `.add-court`, `.del-court` 스타일 추가(무효 강조는 기존 `.void-note/.void-match` 재사용).
- 문서: `메인.md` 064행·현재 상태(060~064 요약)·최근 갱신 갱신. 본 기록 추가. `프로젝트_인수인계.md` 갱신.

주의: 인라인 클라이언트 규칙 — 새 코드는 모두 client() 스코프 내 식별자(`d,editing,nameHTML,esc,draft,$,changed,scheduleHTML,alert,confirm`)만 참조. 새 클래스·명명 함수식 없음 → `keep_names:false`의 `__name` 위험 없음.

## 4. 검증 결과 (본체)

- `node check-login.mjs` PASS(서버·정산 회귀). 클라이언트 모듈 임포트 문법 정상.
- **로컬 브라우저 하니스 실제 클릭 검증**(scratchpad/harness.html: 클라이언트를 그대로 인라인, fetch 스텁으로 목 대진 제공, EDITOR 강제 → 운영진 편집 모드). 정적 서버(scratchpad/server.mjs, 4188)로 브라우저 pane에서 조작:
  - 불참 토글: '가' 지정 → '가'가 낀 R1 1번·R2 1번 경기가 '무효 경기' 표시로 바뀌고 승 버튼 사라짐. 다른 경기·랜덤 라운드는 그대로.
  - 코트 추가: R1에 3번 대진 생성(빈자리 '자'+명단 순), 중복 배치 허용, 휴식 '없음'으로 재계산.
  - 코트 삭제: 추가분 삭제로 2개 복귀. 재인덱싱 검증 — R1 2번 대진에 승(a) 기록(키 0-1) 후 1번 대진 삭제 → 남은 경기가 승(a) 유지하며 키 0-0으로 이동.
  - 가드: 라운드에 경기가 1개일 때 삭제 시 '한 라운드에는 최소 1개의 대진이 있어야 해요.' 알림, 삭제 안 됨.
- 검증용 하니스/서버는 scratchpad에만 두고, 커밋에는 포함하지 않음. 브라우저 확인용 `.claude/launch.json`(머신 종속 경로)은 검증 후 삭제.
