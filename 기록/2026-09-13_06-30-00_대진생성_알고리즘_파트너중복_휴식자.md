# 대진 생성 알고리즘 재정의(랜덤·동일·인접) + 파트너 중복 최소화 + 휴식자 수기 수정

- 작업 시각: 2026-09-13 06:00 ~ 06:35 KST
- 작업 도구: Claude Code (Opus 4.8 본체 — generate() 재구성, Node 시뮬레이션 검증)
- 관련 요청: 070(매칭 방식 정의), 071(파트너 중복 최소화), 072(휴식자 지정·수기 수정)

## 1. 요청 요약

- 070: 랜덤=완전 랜덤으로 코트 배정, 동일=붙어있는(시드 인접) 사람끼리 게임, 인접=동일 사람들에서 바로 위아래 단계로 구성.
- 071: 대진 짤 때 중복 파트너가 최대한 안 생기게, 불가피하면 횟수를 최소화.
- 072: 참가자가 코트 수보다 많아 휴식자가 생길 때 휴식자를 지정하는 기능 + 이후 수기 수정.

## 2. 수행 내용과 변경 파일

- `dist/server/boards-client.js` generate() 재구성:
  - 코트 배정: 랜덤=완전 셔플, 동일·인접=시드 점수 내림차순 정렬 후 붙어있는 4명씩 블록(둘 다 같은 방식). 이전 인접(balanced)의 사분위 라운드로빈(코트 간 실력 분산)은 제거 — 사용자 정의(동일 사람들에서 한 단계)에 맞춤.
  - 팀 나누기(4명→두 팀) 선호 순서: 동일=(0,1)vs(2,3) 붙어있는 둘, 인접=(0,2)vs(1,3) 한 단계 위아래, 랜덤=순서 무관.
  - 파트너 중복 최소화(071): 라운드 간 파트너(팀메이트) 쌍 카운트(pairCount)를 유지. 각 코트에서 3가지 팀 분할 중 (두 팀의 기존 파트너 횟수 합)이 가장 작은 것을 선택하고, 동점이면 method 선호 순서. 선택 후 카운트 증가.
- 072 휴식자 수기 수정: 생성 직후 `editSchedule` 편집 화면에서 각 선수 자리가 드롭다운이라, 쉬는 사람을 슬롯에 넣으면 기존 선수가 휴식으로 밀려나고 rest가 자동 재계산된다(기존 onchange 로직). 별도 코드 없이 동작 — 코드 추적으로 확인. 생성 시점의 사전 지정 전용 UI는 이번엔 추가하지 않음(필요 시 후속).

## 3. 검증 결과

- Node 시뮬레이션(scratchpad/gen-sim.mjs, 12명·3코트·5R):
  - 동일: 경기당 4명 점수폭 15(붙어있음), 팀=(P0,P1)vs(P2,P3).
  - 인접: 같은 코트(점수폭 15), 팀=(P0,P2)vs(P1,P3).
  - 랜덤: 점수폭 큼(완전 랜덤), 파트너 반복 0.
  - 파트너 중복: 12명 쉼 없음(고정 4인조)이라 반복이 불가피한 최악 조건에서도 같은 파트너 최대 2회(6개 쌍에 10개 인스턴스 분산 = 이론상 최적).
- `node check-login.mjs` PASS(인라인 클라이언트 빌드 무결성). generate()는 외부 스코프 참조 없음(인라인 안전).
