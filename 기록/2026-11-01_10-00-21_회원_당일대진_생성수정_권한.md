# 요청151 — 회원 당일 대진 생성·수정 권한

## 요청과 적용 범위

- 회원 로그인 후 대진표에 회원 대진 만들기 버튼. 별도 지정 암호 확인 후 당일 대진 생성·수정만 허용.
- 추가 확인: 당일 대진이어도 회원에게 마감 관련 권한은 없다. 예/출석만 반영/미반영마감/마감 취소는 항상 운영진 전용. 버튼 숨김과 서버 거절을 모두 유지한다.
- 한국 시간 기준 오늘의 미마감 대진만 편집. 지난 날짜·미래 날짜·마감본 수정, 삭제, 마감/취소, 공지·시드·장부·실시간 운영진 기능은 허용하지 않는다.
- 암호와 운영진 키 원문은 소스·문서·테스트에 기록하지 않는다. 서버 검증값으로 설정하고 자정 만료·회원 세션 연결·시도 제한을 적용한다.
- 생성 시 실제 날짜 필드 저장. 기존 대진 날짜는 명확한 제목 날짜와 생성 연도로 보수적으로 판단하며 임의로 오늘로 바꾸지 않는다.
- 기존 대진을 수정하는 회원은 제목/날짜를 변경할 수 없다. 운영진 기존 권한은 유지.
