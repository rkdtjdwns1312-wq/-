# 요청139 — 콕끼리 배드민턴 가로 배너

## 요청·설계

- 메인 그림을 메뉴 버튼 영역 전체 가로 너비로 확장한다. 기존 마스코트를 오른쪽 코트에 배치하고 왼쪽에는 같은 빨간 운동복이지만 조금 다른 여성스러운 콕끼리, 중앙에는 배드민턴 코트와 네트를 배치한다.
- imagegen 스킬/내장 이미지 생성 도구로 기존 public/mascot-play.png를 참조한다. 원본은 보존하고 새 자산으로 추가한다. 모바일은 전체 그림을 잘리지 않게 비율 유지 축소한다. 글자/기능/DB 변경 없음.
- 헤더 요청138 기록7143a2a push 및 작업 전 pull 최신 확인. 이미지 생성/통합 본체, 경량 에이전트 CSS/클라이언트, Astra 최종 검토.

## 검증·배포

- `node check-member-ui.mjs`: PASS (홈 배너 경로·대체텍스트·2172×724 속성, 전용 CSS, desktop/mobile 여백, 빈 게시판 이미지 비영향).
- `node check-login.mjs`: PASS. 최종 PNG2172×724 확인. 재생성 이미지의 중앙 원근 네트가 좌우 코트를 분리하고 셔틀콕이 네트 위에 있음을 눈으로 확인.
- `check-login.mjs --serve` 정적 자산 allowlist에 mascot-play/rest/court-banner 3개 경로만 GET/HEAD 허용, 임의 파일 접근 불가. 본체의 실제 브라우저 검증: 데스크톱 배너/메뉴1040px 일치,390px화면343px 일치,320px화면281px 일치, 가로넘침없음/이미지 정상로드/캐릭터잘림없음. 모바일 증빙 `2026-10-25_홈_배너_모바일.png`.
- GPT-6 Luna 코드/회귀, 별도 GPT-6 Astra 최종 검토·전체검사PASS. 에이전트의 loopback제한은 본체브라우저로 보완했다. 공개 배포 대기.

## 이미지 제작

- 내장 image_gen 도구 사용, 기존 mascot-play.png를 view_image로 확인 후 참조. 생성 결과2172×724(3:1), `public/mascot-court-banner.png`로 원본 그대로 복사. 기존 mascot-play/rest는 보존.
- 최종 프롬프트: 기존 귀여운 회색 콕끼리 얼굴·분홍 귀·머리털·빨강/흰색 V넥 운동복·반바지·운동화를 유지한 오른쪽 캐릭터와, 같은 운동복에 둥근 얼굴·은은한 속눈썹·작은 빨간 리본으로 구별된 왼쪽 여성스러운 상대. 두 캐릭터 전신·발·라켓이 잘리지 않는 넓은3:1장면, 중앙 초록 배드민턴 코트/흰라인/네트 및 셔틀콕. 원본의 굵고 부드러운 윤곽·질감있는 음영·크림색 실내체육관 배경 유지. 글자·로고·워터마크 금지, 한 장의 연결된 가로 배너.
- 생성물 시각 확인: 요청한 양쪽 캐릭터·운동복·중앙 코트, 비율/발/라켓 표시 확인. 이후 사이트에서 원본비율 유지 적용.
- 사용자 후속 보완: 첫 그림의 네트가 뒤로 동떨어져 두 캐릭터가 같은 편처럼 보이므로, 좌우 코트를 분리하는 네트의 방향/원근을 고쳐 서로 네트 너머로 셔틀콕을 넘기는 구도로 재생성한다. 첫 그림은 공개 배포하지 않았다.
- 최종 수정 프롬프트: 첫 그림을 참조해 캐릭터/운동복/화풍/3:1을 유지하되 시점을 코트 긴 옆선의 약간 높은3/4뷰로 변경. 네트는 뒤쪽 가로장벽이 아니라 중앙에서 앞기둥(55%너비,90%높이)→뒤기둥(45%,35%)으로 뻗는 원근감 있는 대각 평면으로 좌우를 분리. 왼쪽은 타격 후/오른쪽은 리시브 준비, 셔틀콕은 네트 위를 왼쪽에서 오른쪽으로 넘는다. 두 콕끼리 발은 각자의 코트에 두고 전신/라켓 자름없음. 글자/로고없음.
- 두 번째 생성본2172×724를 동일 프로젝트 자산 경로에 반영. 실제 확인: 중앙네트가 앞뒤로 뻗어 두 캐릭터의 코트를 나누고 셔틀콕이 그 위로 이동하는 구도다. 기본 생성원본들은 Codex 생성 폴더에 남아 있고 프로젝트에는 최종 선택본만 사용한다.

## 핵심 명령

기존 콕끼리와 여성스러운 상대가 중앙 배드민턴 코트를 사이에 둔 가로형 그림을 메뉴 너비로 적용한다.
