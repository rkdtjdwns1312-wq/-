# 회원 이관 순위 화살표 보존과 정산 대상 표시·최저 20점 보호

## 원인

회원 추가·숨김·게스트 이관의 재정렬 코드가 모든 회원의 previous_rank를 현재 rank로 덮어써 화살표가 사라졌다. 또한 이전 순위와 현재 순위를 직접 비교해, 정모에 나오지 않고 다른 사람의 점수 변동으로 밀린 사람에게도 화살표가 표시됐다.

## 구현과 판단

- rank_movement에 정산 직전/직후 순위 차이를 저장한다. 유효한 비랜덤 경기에서 승 또는 패가 집계된 회원만 대상이며, 미참가·불참·출석만 반영된 사람은 0이다.
- 명단 추가·삭제·이관은 현재 순위만 재정렬하고 기존 정모 증감·보호 상태를 보존한다. 이관되는 사람은 회원 순위의 과거 기준이 없어 순위 화살표는 0이며, 점수 변동·출석·승·패·보호 상태는 보존한다.
- 이미 없어진 화살표는 마이그레이션 0011에서 최신 ranking_events의 rank_before/rank_after로 복구한다. attendance와 updated_at을 정산 시점과 대조해 새 정모 생성/마감 취소로 초기화된 표시는 복구하지 않는다.
- 정산은 모든 라운드의 출석+승-패를 합산한 뒤 최저 20점을 적용한다. 비랜덤 유효 경기 정산 대상의 계산 결과가 **20점 이하(20 포함)**면 보호 대상이다. 실제 승·패 횟수는 감추거나 줄이지 않는다.
- 보호 대상은 20점 그룹의 일반 회원 뒤에 배치한다. 먼저 보호된 사람 뒤에 최근 보호된 사람을 배치하며, 같은 정산 내 보호 대상은 이전 순서를 유지한다. floor_protected_at은 동점 정렬용으로 유지한다.
- rank_protected는 이번 정모 표시용이다. 변동 칸에 화살표 대신 작은 11px '보호적용' 문구가 나오며 게스트 탭도 동일하다. 새 정모 생성 시 화살표·보호 문구는 초기화하되 현재 점수와 보호 후 정렬 순서는 유지한다.
- 기존 20점 미만 점수는 모두 20(E)로 올린다. 이전 정산 원본 이벤트는 보존하고 기존 previous_points는 최소 20으로 보정해 행정 보정을 경기 득점으로 표시하지 않는다.
- 실제 적용된 점수 증감만 정산 이벤트에 저장한다(예: 20점에서 계산상 -1이면 실제 증감은 0). 마감 취소는 이전 보호 상태와 실제 점수 증감을 복원한다. 이전 버전의 20점 미만 이벤트도 20점 기준으로 환산해 취소한다.
- ranking_settlements.rank_order_before에 직전 회원 순서를 저장해 보호로 바뀐 동점 순서도 마감 취소 시 정확히 복원한다. 이 경계 사례를 추가한 뒤 필수 테스트를 다시 실행해 PASS했다.
- 향후 이관 시 promoted_guest_id를 보관해, 게스트로 정산한 뒤 회원으로 이관하고 마감 취소해도 현재 회원 행의 점수·출석·승·패를 되돌린다. 과거 이관자의 원본 게스트 ID를 임의로 추정해 매칭하지 않는다.
