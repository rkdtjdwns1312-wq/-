# 요청 094 — 대진 진행 상태 버튼과 테두리 강조

## 요청

각 경기 오른쪽 위에 작은 대기중 버튼을 표시하고 누르면 대진중과 활성 테두리, 승리 기록 시 자동으로 대진종료 및 테두리 해제.

## 계획

- 상태는 대진 게시글 payload의 matchProgress에 저장하여 회원·운영진이 함께 보고 새로고침해도 유지한다. 점수 정산과는 독립적이다.
- 승리 결과가 있으면 종료를 우선 표시한다. 마감/불참 무효 경기는 변경을 막는다. 버전 충돌 시 승패·명단 덮어쓰기를 막는다.
- 기존 대진은 별도 이관 없이 승패가 있으면 종료, 없으면 대기 상태로 읽는다.
- 대진 편집 중 이름/코트 변경 시 달라진 경기의 진행 상태를 정리한다.
- 랜덤 라운드는 기존 승패 미기록 규칙을 유지하며 진행 버튼으로 종료할 수 있게 한다(점수/출석 추가 반영 없음).

## 모델·진행 상태

- Codex 본체: 서버 상태 저장·동시성·회귀 검사.
- Terra: 상태 배지·활성 테두리 및 상태/승리 기록 UI 구현. Astra: 통합 검토와 비동기 저장 보완.
- 초기 필수 회귀 PASS. 로컬 브라우저에서 대기중→대진중 테두리→승 클릭 후 대진종료/강조 해제 확인.
- Astra 검토에서 마감 중 상태 입력 경쟁 조건, 저장 성공 후 조회 실패 처리, 저장 중 편집 화면 덮임을 발견했다. 마감 버전 확보와 NOT NULL 원자성 가드 및 경쟁 재현 회귀를 추가했고 UI도 보완한다.
- 마감 경쟁 테스트는 상태 입력을 마감 읽기와 batch 사이에 끼워 넣어 409와 점수·정산·이벤트 전부 불변을 확인한다. D1 batch 롤백은 Cloudflare 공식 문서로 확인했다.
- 실제 운영 대진으로 테스트 승패/마감을 실행하지 않는다. 로컬 가상 대진으로 검증한다.

## 핵심 명령

대기중→대진중→대진종료 상태를 경기별로 공유하고 진행 중인 경기의 테두리만 강조한다.
