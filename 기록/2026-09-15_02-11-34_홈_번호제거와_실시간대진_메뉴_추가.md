# 홈 번호 제거와 실시간대진 메뉴 추가

- 요청: 095
- 시작: 2026-09-15 02:11 KST
- 홈 공지사항·대진표·시드현황의 01·02·03 숫자를 제거한다.
- 대진표와 시드현황 사이에 같은 디자인의 `실시간대진` 메뉴를 추가한다.
- 작은 설명 문구는 `오늘의 자유대진`으로 표시한다.
- 사용자 확인: 별도 자유대진 화면이며 운영진이 `코트 생성하기`에서 지정한 개수만큼 빈 대진을 연다. 모든 회원이 이름을 직접 수기로 입력한다. 자유대진 승패는 시드현황에 전혀 반영하지 않는 임시 정보다.
- 현재 코트 상태만 D1에 공유 저장하고 다음 코트 생성/해당 코트 다음 경기 준비 시 초기화한다. 정모 정산·시드·출석·순위 및 영구 승패 이력에는 연결하지 않는다.
- 기존 코트 전체를 새로 만들 때는 운영진만 가능하며 초기화 확인과 동시 저장 버전 보호를 둔다.
- 최종 추가 지시: 실시간대진에는 승패 버튼도 필요 없다. 자유대진 승패 필드/API/UI 자체를 만들지 않고 진행 상태만 수동 종료한다. 기존 날짜별 정모 대진의 승 버튼·정산은 그대로 유지한다.
- 입력 UX 추가 변경: 코트 안의 이름칸을 직접 편집하지 않는다. `실시간대진 들어가기` → 이름·빈 코트 선택 → `완료`로 첫 빈자리에 등록한다. 이름 수기 입력은 이 입장 창에서만 한다. 대기중 참가 취소로 오입력 복구가 가능하며, 이미 대기/진행 중인 이름의 중복 입장은 막는다.
- 093·094와 함께 작업하며 동일 클라이언트 파일은 담당자 완료 후 순차 수정한다.

## 결과

### 최종 합의 (위 중간 설계보다 우선)

- 코트가 모두 차면 `대기중인 다음 대진` 아래 `대기중인 대진 1, 2, 3…`을 세로로 표시하고 각 대진의 네 이름은 한 줄로 표시한다.
- 코트 내 4명이 차면 `대진 종료` 버튼이 자동 표시된다. 누르면 기존 이름을 비우고 다음 대기 대진이 해당 코트로 즉시 이동한다. 대기가 없으면 빈 코트다.
- 자유대진은 VS·팀 구분·승패 버튼·별도 시작/다음 경기 준비 버튼을 두지 않는다. 팀은 현장에서 정한다.
- 대기중/대진중/승 기록 자동 종료 상태 버튼은 기존 날짜별 정모 대진에만 적용한다(094). 자유대진과 혼동하지 않는다.
