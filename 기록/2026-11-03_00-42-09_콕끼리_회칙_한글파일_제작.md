# 콕끼리 회칙 한글 파일 제작

- 요청 번호: 155
- 요청: 수정된 회칙을 HWP 파일로도 제공.
- 기준: `자료/콕끼리_회칙_초안.md`의 2026-11-03 보완본. 회칙 및 선납 기간은 2026-11-21~2027-04-30.
- 홈페이지 코드, 데이터베이스, 회칙의 의결 상태는 변경하지 않는다. 검토용 초안이다.

## 진행

- 설치된 한글 2018을 확인하고 Windows 컴퓨터 조작 도구로 HTML 원본을 불러왔다.
- 최초 변환에서 별표의 검은 배경을 발견하여 HTML 표에 흰색 배경을 명시했다.
- HWP 본문과 원본의 모든 문단·표 셀을 비교할 검증 스크립트를 준비했다.
- 문서 연결 세션은 없었으며, 한글의 문자 코드 확인 대화상자는 자동 조작 도구의 창 활성화 오류로 직접 확인 클릭을 요청했다.
- 사용자가 문자 코드 확인과 최종 HWP 저장을 직접 완료했다고 확인했다. 자동 저장 완료로 주장하지 않는다.
- 바탕화면에 사용자가 저장한 `콕끼리_회칙_HWP원본.hwp`를 읽어 저장소 `자료/콕끼리_회칙_초안.hwp`로 복사했다. 바탕화면 원본은 변경하지 않았다.
- 6쪽 문서의 첫 페이지와 별표 표시를 확인했고, 흰색 표 배경과 본문 표시가 정상이다.
- HWP 변환용 원본과 생성·검증 스크립트도 함께 보관한다. 작성 근거 섹션만 배포 문서에서 제외하고 본문, 부칙, 별표, 채택 전 확인사항은 모두 유지했다.

## 검증

- 번들 Node `check-login.mjs`: 전체 PASS.
- `scripts/verify-club-rules-hwp.mjs`: PASS. 실제 HWP 5 복합 문서, 65,536바이트. 압축된 본문 스트림을 읽어 원문의 162개 문단·표 셀 전체 보존 확인.
- 본체가 문서 변환과 검증을 수행했으며 하위 에이전트 위임은 하지 않았다.
