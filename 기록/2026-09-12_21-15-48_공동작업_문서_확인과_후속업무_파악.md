## 요청과 작업 기준

사용자가 https://kokkiri.kokkiri-badminton.workers.dev/ 를 작업 대상으로 지정하고 메인·에이전트 MD 확인과 업무 파악을 요청했다. 이어 Claude·Codex 공동 작업 준비를 마쳤다고 설명했다.

- 실제 소스와 문서: `kokkiri-site/`.
- `메인.md`: 요청 이력·현재 상태의 공통 기준. `AGENTS.md`: Codex 절차. `CLAUDE.md`: Claude 절차와 공통 기록 규칙.
- 상세 기록은 한국 시간의 날짜·시간·작업 제목으로 저장하고 마지막에 핵심 명령을 남긴다.
- GitHub origin/main이 공통 소스이고 push는 Cloudflare 자동 배포를 유발한다. 옛 Codex Sites 배포 지시문은 사용하지 않는다.
- 최초 데이터 기준은 2026-09-10 관리표의 회원 61명·게스트 32명. 주밤·로토 시드는 이후 사용자 확인(023)에 따라 A로 처리한다.

## 확인 결과와 한계

- 작업 시작 시 main의 작업 트리는 깨끗했다.
- 로컬 HEAD와 원격 `git ls-remote origin refs/heads/main`이 모두 `c3c019acc62818cef6248edc3debfaeb1aeb1184`로 일치했다. 조회 시점에 가져올 새 커밋이 없어 pull은 하지 않았다.
- 최신 커밋은 요청 053의 동시 작업 중복 문서 행 정리다.
- 공개 홈 GET: HTTP 200, 제목 `콕끼리 · 콕하나로 우리끼리`. HTML에 round-tabs·settled-tag가 포함되어 있었다. 이것만으로 전체 화면 동작을 검증한 것은 아니다.
- 최근 기록에는 5초 갱신·라운드 탭·회원 승패 기록·랜덤 경기 채점 제외·MVP·운영진 마감·최근 마감 취소·목록 마감 태그까지 완료·배포로 적혀 있다.
- 코드에서 로그인 form의 onsubmit, 5초 갱신, unsettle 라우트와 최근 마감 제한을 확인했다. 실제 로그인·승패 기록·마감·마감 취소는 수행하지 않았다.

## 남은 업무 판단

현재 확정된 신규 기능 개발 요청은 없다. 다음은 기존 문서의 점검·정리 후보이며 이번에 구현하지 않았다.

1. 참가자·코트 변경 창 재진입 시 라운드별 방식·늦참 선택 유지. 요청 033 기록에 초기화 문제가 남아 있고 현재 openPicker에서도 lateIds가 빈 Set으로 시작한다.
2. 운영진 로그인 Enter 제출의 실제 화면 확인. 코드에는 submit 처리가 있지만 과거 기록의 브라우저 검증은 미완료다.
3. 주밤·로토 원본 엑셀 시드 열 정정 여부 확인. 이번에는 엑셀을 다시 열거나 수정하지 않았다.
4. 메인 문서의 오래된 상태 정리. 이력 032가 033 행에 섞여 있고, 초기 배포 대기·비밀값 입력 대기·대진 종료 표현·기록 개수가 오래되었다. 신규 마이그레이션 안내의 0005도 이미 사용 중이다.

- 번들 Git의 HTTPS helper 탐색 오류는 명령별 `GIT_EXEC_PATH`를 `C:/Users/just/.cache/codex-runtimes/codex-primary-runtime/dependencies/native/git/mingw64/bin`으로 지정해 해결했다. 영구 환경 설정은 바꾸지 않았다.
- 샌드박스의 네트워크 제한으로 공개 홈·GitHub 조회가 막혀 읽기 전용 명령에 승인을 요청했고 승인 후 성공했다. 과거 사용량 제한을 현재 차단 사유로 가정하지 않는다.
