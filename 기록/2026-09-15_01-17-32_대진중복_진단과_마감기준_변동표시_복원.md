## 091 구현 내용

- `dist/server/weekly-results.js` 추가: 최신 남은 마감 이벤트를 공통 조회. 과거 초기화된 표시 컬럼과 무관하게 주간 출석·승패·실제 점수 차이·순위 차이·보호 문구 복원. 이관자는 `promoted_guest_id`로 연결, 명단 변경 후에도 정산 당시 화살표 유지.
- `boards.js`: 새 대진 저장의 초기화 제거. 마감 시 해당 정모 출석/승패만 캐시에 저장. 회원 랭킹 및 게스트 명단 조회에 이벤트 기반 표시 적용. 마감 취소 시 남아 있는 직전 정산의 표시로 돌아감. 백업 JSON에 정산·회원/게스트 이벤트 추가.
- `boards-client.js`: 마감 확인 메시지에 이 대진의 결과로 표시가 바뀐다는 설명.
- 운영 DB 점수/순위/대진을 직접 변경하거나 재정산하지 않았다. 별도 마이그레이션도 없다. 기존 영구 점수는 현재 행, 주간 성적은 정산 이벤트가 기준이다.
- API previous_points는 이벤트의 실제 증감을 위한 표시 기준값이며 과거 DB 캐시와 같을 필요는 없다. 정산 뒤 수동 점수를 수정해 초기화한 사람은 people_changes 및 초기화 캐시로 구분하여 화살표/보호를 다시 살리지 않는다(주간 출석·승패는 보존).
