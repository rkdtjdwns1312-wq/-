# 조퇴 라운드 지정과 중복 휴식 방지 (요청 152)

- 사용자 요청: 늦참 오른쪽 조퇴 버튼, 후반 라운드 제외, 조퇴하는 게스트·운영진의 앞 경기 역할 휴식 방지.
- 해석: 3라운드를 고르면 3라운드부터 마지막까지 제외한다. 늦참과 함께 선택할 수 있으며 실제 참석 가능 라운드만 배정한다.
- 저장: 대진 `earlyFromRounds` 이름별 시작 라운드, 생성 명단 `earlyFromRound`, 라운드별 `early` 표시.
- 자동 편성뿐 아니라 저장 검증·수동 교체·긴급교체·출석 정산에도 같은 참석 가능 범위를 적용한다.
- 조퇴 예정 게스트·운영진은 역할/신청늦음 우선순위 휴식을 추가로 받지 않는다. 편성 불가능하면 이유를 안내한다.
- 분담: GPT-6 Luna 알고리즘·회귀 검사, GPT-6.1 Terra UI·UI 검사, 본체 서버·통합·기록, GPT-6 Astra 최종 검토.
- 완료: 구현·검증·공개 배포 확인. 운영 데이터로 테스트 대진/정산하지 않았다.

## 검증

- 새 검사 3개를 필수 `check-login.mjs`에 통합: 알고리즘, 실제 UI 함수, 실제 API/메모리 SQLite. 전체 PASS.
- 세 방식·여러 난수 seed, 게스트/운영진 역할·신청늦음·늦참 조합, 조퇴 이후 배치/수동교환 금지, 편성 불가 안내를 검사했다.
- 서버 저장·재조회·잘못된 입력·조퇴 전/후 긴급교체, 늦참과 조퇴 겹침/1라운드 조퇴 출석 0, 일부 출전 승패와 출석 1, 마감 취소 원복 PASS.
- 로컬 실제 브라우저: 회원 8명+게스트 1명, 2코트·4라운드(랜덤/동일/인접/랜덤), 게스트 조퇴 3 지정. 1·2라운드 출전/추가휴식 없음, 3·4라운드 조퇴 표시 및 수동 선택지 제외 확인. 저장 후 재수정·참가자 변경 창에서 조퇴 3 유지 확인.
- 모바일 너비 390px: 늦참 오른쪽 조퇴 버튼이 같은 줄, dialog 가로 넘침 없음 확인. 긴 선택 설명은 버튼 아래 별도 표시한다.
- 공개 데이터로 대진 생성/수정/마감 시험은 하지 않았다.
- GPT-6 Astra 통합 최종 검토: 차단 문제와 필수 테스트 누락 없음. 전체 검사 및 diff 공백 검사 PASS. 공개 배포 확인은 아래 후속 기록에 남긴다.
