# 대진표 밖 참석 명단을 누적출석에만 반영 (요청 158)

- 사용자 제공 범위: 2026-08-07부터 2026-11-01까지 15개 날짜.
- 날짜별 같은 이름 중복을 제거해 수동 출석 186건으로 정리했다.
- 사용자 확인과 정정에 따라 `동→동이`, `엽→엽이`, `피글렛→피클렛`, 2026-09-02 `네코→네오`, 2026-09-05 `로토리버→로토·리버`로 저장했다.
- 2026-08-19 `머우`, 2026-08-29 `현이`의 같은 날짜 중복은 각각 1회로 처리했다.
- 기존 대진표 편성 날짜와 수동 확인 날짜를 회원별 `Set`으로 합쳐 같은 날짜는 최종 1회만 계산한다.
- 수동 명단은 현재 회원 이름 또는 회원 이름 변경·게스트 승격 이력에 한 명으로 확정될 때만 해당 회원에게 연결한다. 아직 회원이 아닌 이름도 기록을 보존해 이후 회원 전환 시 연결할 수 있다.
- 화면 안내를 `대진 편성 또는 운영진 확인 날짜 기준`으로 바꿨다.
- 수동 출석 테이블은 자동 백업에 포함한다.

## 점수 격리

- `manual_attendance`는 날짜·이름·제보 이름·등록 시각만 저장한다.
- 시드 점수, 기존 출석점수, 승, 패, 순위, 정산 이벤트를 수정하는 SQL이나 API는 추가하지 않았다.
- 마이그레이션 적용 전후의 회원·게스트 점수/승패/순위/정산 이벤트 스냅샷이 완전히 같은지 자동 검사한다.

## 검증

- 15개 날짜·186건, 잘못된 날짜, 중복 제거, 이름 별칭, 기존 대진과 합집합, 마이그레이션 재실행을 검사했다.
- 백업 다운로드에 186건과 모든 필드가 보존되는지 검사했다.
- `node check-login.mjs` 전체 회귀 검사 PASS.
- 고성능 최종 검토에서 차단 결함 없음. 권고한 잘못된 월 차단과 백업 직접 검사를 추가한 뒤 전체 검사를 다시 PASS했다.
- 실제 운영 점수·승패·순위·대진은 시험 수정하지 않았다.

## 배포

- 기능·자료 커밋 `b70c854`를 `origin/main`에 push했다.
- GitHub `test`와 Cloudflare `Workers Builds: kokkiri`가 모두 성공했다. 배포 명령은 D1 마이그레이션 적용 후 Worker를 게시한다.
- 공개 홈 HTTP 200과 `대진 편성 또는 운영진 확인 날짜 기준` 팝업 코드 반영을 확인했다.
- 실제 운영 점수·승패·순위·대진 데이터는 변경하거나 시험 정산하지 않았다.

## 핵심 명령

대진표에 없던 날짜별 참석 명단은 누적출석에만 합산하고 점수·승패·순위에는 반영하지 않는다.
