# 102 — 동일·인접 전체 라운드 파트너 중복 재탐색

- 착수: 2026-09-17 23:39 KST
- 사용자 요청: 랜덤을 제외한 동일·혼합 경기를 모아서 팀 파트너 중복 시 다른 조합을 탐색해 배치.
- 시작: main 40ba09f, clean, git pull --ff-only origin main 최신.
- 혼합은 기존 화면의 인접(method=balanced)으로 해석하며 명칭은 임의 변경하지 않는다.

## 설계 및 확인

- 종전 gap 우선·동률 repeats 규칙은 균형이 유일한 조합을 계속 반복하게 했다. 현재 pairCount는 랜덤 파트너도 포함한다. 추가 코트는 앞선 라운드만 비교해 미래 동일/인접 중복을 놓친다.
- 새로운 사용자 요청에 따라 동일/인접의 파트너 중복을 우선 줄이고, 중복 정도가 같을 때 점수 균형을 비교한다. 랜덤 파트너는 집계하지 않으며 랜덤 경기 자체도 후처리에서 바꾸지 않는다.
- 늦참/휴식·코트 수·경기 인원 및 현재 시드 점수는 유지한다. 저장된 경기/승패/수기 교체를 자동 재편성하지 않는다.
- 사용자 확인: **다른 코트와도 선수를 바꿔 중복을 최소화**. 같은 라운드의 경기 참가자만 교환하며 휴식·늦참자를 새로 출전시키지 않는다.
- 인원/라운드 제약이나 탐색 한계로 모든 중복 제거를 보장할 수는 없다. 실제 남은 중복은 정확히 집계한다.

## 분담과 검증

- 본체: 팀 조합 탐색·회귀·통합/기록.
- Terra: 추가 코트의 전체 비랜덤 이전 경기 수집 및 UI 문구·실제 함수 검사, 두 파일만 분담.
- 최종 Astra 점검 및 필수 검사 PASS. 추가 메모리 160건에서 중복 목적함수 악화 없음·집계 정확·랜덤/휴식/늦참/출전자 보존 확인. 전역 최적해 보장은 아니며 남은 중복은 솔직히 표시한다.
- 실제 운영 대진·점수·명단을 시험으로 변경하지 않는다.

## 구현 내용

- schedule-tools.js: 중복 팀의 추가 등장 횟수 → 반복 집중도(각 쌍 횟수의 조합수) → 팀 점수 합계 차이 순으로 비교한다. 같은 경기 인원에서는 합계 차이와 평균 차이의 최적 조합이 같다.
- 자동 생성 후 동일/인접 전체 경기 재탐색: 4명 내 세 팀 분할 → 서로 연결된 두 경기의 분할 동시 변경 → 필요 시 같은 라운드 두 코트 8명의 315가지 팀/코트 조합 비교. 오직 목적함수가 개선될 때만 채택한다. 코트 간 교환은 점수만 좋아진다는 이유로 수행하지 않는다.
- 탐색 횟수 제한(고정 그룹 약 24,000 후보·코트 교환 약 180,000 후보)으로 큰 대진이 오래 멈추지 않게 한다. 최적 해를 증명하는 알고리즘이 아니라 제한된 개선 탐색이다. 모든 중복 제거를 보장하지 않는다.
- 랜덤은 파트너 집계/후처리에서 제외한다. 쉬는 사람·늦참 라운드·라운드별 출전자와 코트 수는 유지한다.
- 추가 코트는 기존 전체 비랜덤 경기(뒤 라운드 포함)를 참조하여 새 코트의 팀만 편성한다. 기존 수기 조합/승패는 바꾸지 않는다.
- 편집 화면에 `동일·인접 경기의 팀 파트너 중복이 없습니다.` 또는 `팀 파트너 중복 N건이 남았습니다…`를 표시한다. N은 파트너 쌍별 첫 등장 이후 추가 등장 수다.
