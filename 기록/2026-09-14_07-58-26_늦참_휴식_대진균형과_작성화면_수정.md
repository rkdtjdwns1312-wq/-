# 요청 084~087 — 늦참·휴식·대진 균형과 작성 화면 수정

- 시작: 2026-09-14 07:58 KST
- 한도 제한 중 대화로 준비한 요청 1~4와 버그 정정 내용을 현재 실행하라는 사용자 지시에 따라 착수.

## 요청과 계획

1. 늦참 1~5 선택: 2이면 1·2R 대진/휴식에서 제외하고 3R부터 참여. 신청늦음 별도 선택·저장.
2. 휴식: 신청늦음→게스트→운영진 우선, 이 대상은 총 1회. 그다음 일반회원 무작위. 사용자 확답: 일반회원은 모두 한 번 쉰 뒤에도 칸이 더 필요하면 덜 쉰 사람을 우선해 추가 휴식 허용.
3. 동일·인접은 저장 후 상세에는 보이나 작성 중에 공백. 원인 재현·수정. 점수순 동일 1234 묶음에서 13/24 또는 14/23 중 평균 균형 선택, 인접 1256·3478 묶음에서 16/25·38/47처럼 구성.
4. 수기 편집은 선택한 자리만 바꾸고 다른 자리는 그대로. 같은 라운드 다른 경기에 중복 출전 허용.

## 수행 내용과 모델 분담

- Astra 본체: 생성·저장 규칙 설계, 통합·회귀 검증, 최종 검토.
- GPT-5.6 Terra(medium) 1명: `boards-client.js`, `boards-style.js`에서 늦참 UI·편집 연결·CSS 구현. 서로 연관된 여러 화면을 변경하므로 Luna보다 높은 중간 난도로 분담. Astra가 최종 검토하며 미적용 CSS 선택자 등을 보정.
- `schedule-tools.js` 신설: 외부 의존성 없는 factory를 페이지에서 직렬화해 client의 세 번째 인자로 전달. generate/availableNames/refreshRound/replacePlayer를 서버와 브라우저에서 공유.
- 동일은 4명 블록, 인접은 8명 블록에서 1256·3478 구성(남는 4명은 같은 코트). 팀 평균 차이를 최소화하고, 동점일 때 파트너 반복을 최소화한다. 알파벳 급수 4단계가 아니라 사용자 예시의 점수순 간격을 따른다.
- 늦참 1~5, 신청늦음을 payload에 저장해 재편집 시 복원. 신청늦음은 앞 라운드 제외와 독립 선택. 미도착자는 대진·휴식에서 제외, 전체 라운드 종료까지 미도착이면 출석 0. 도착자가 4명 미만인 라운드는 대진 0개와 안내 표시.
- 이름 수기 수정은 해당 자리만 변경하고 그 경기 승패만 초기화. 다른 경기 출전·결과는 보존. 한 경기 내 중복과 미도착자 배정은 차단.
- 우선대상 휴식 1회 제한을 충족할 수 없는 조합은 입력창에서 코트/인원/라운드 조정 안내. 자동 생성으로 제한을 넘기지 않는다. 수기 편집은 운영진의 예외 편성 요청을 허용한다.
- 기존 운영 DB와 게시된 대진표를 재생성/재정산하지 않았다. DB 마이그레이션은 불필요하다.

## 버그 원인과 수정

- 기존 코드를 로컬에서 7코트로 재현. 동일/인접의 경기 데이터와 select option은 존재했으나 각 카드 폭 236px에서 선택칸이 16px로 줄어 이름 대신 화살표만 보였다. 랜덤에는 승패 버튼이 없어서 상대적으로 덜 줄었다.
- 편집 grid 최소 320px, 팀 grid 및 min-width 보정. 가운데 승패 버튼은 편집 화면에서 각 팀 아래로 배치해 이름 공간을 확보. 최종 이름 선택칸은 데스크톱 약102px, 390px 휴대폰 약101px로 확인했다.
- Terra 초기 CSS의 `.edit-match .matches` 선택자는 실제 DOM과 맞지 않아 Astra가 `#editMatches .matches`로 수정했다. 첫 보정 후에도 58px여서 일부 글자가 잘려 승 버튼을 팀 아래로 이동해 해결했다.
- 브라우저의 native confirm 처리에서 테스트 탭 응답이 멈춘 적이 있어 새 임시 탭에서 확인창 없는 신규 생성 흐름으로 재현했다. 실제 운영 화면/데이터에는 영향을 주지 않았다.
