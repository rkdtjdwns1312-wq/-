# '대진 종료' 버튼이 안 뜨는 이유 진단·미기록 라운드 안내와 확인창 검증

- 작업 도구: Claude Code (Fable 본체 직접 처리 — 진단·소규모 UI 추가, 로컬 브라우저 실동작 검증)
- 관련 요청: 052 (질문: 승 체크 다 했는데 '대진 종료'(대진마감) 버튼이 왜 안 뜨나 + 예/아니오 확인창 검증)

## 1. 요청 번호와 요청 요약

- 요청 052: 승 체크를 다 했는데 '대진 종료' 버튼이 안 뜨는 이유 확인. 그리고 '대진 종료'를 누르면 "정말 마감하시겠습니까? 예/아니오"까지 뜨는지 검증.

## 2. 진단 (Fable/본체)

- '대진 종료' 버튼 조건: `EDITOR(운영진) && schedule && !settledAt && allScoredDone`. `allScoredDone`은 모든 라운드가 (random) 또는 (그 라운드 모든 경기에 승패 기록)일 때 참.
- 로컬 재현: legacy 대진표(4라운드, 각 1경기)의 4경기를 모두 기록하니 운영진 화면에 버튼 정상 표시. 즉 로직은 정상.
- 안 뜨는 실제 원인 추정: (1) 운영진 모드가 아님(회원 링크로 보면 버튼 없음), (2) 라운드 탭(049) 도입 후 다른 라운드로 넘겨 기록하지 않아 일부 라운드가 미기록. 라운드 탭 때문에 미기록 라운드가 눈에 안 띄는 것이 핵심.

## 3. 수행 내용과 변경 파일 (Fable 직접 처리)

- `dist/server/boards-client.js`:
  - scheduleHTML 라운드 탭: 미정산 상태에서 결과가 다 안 찬 채점 라운드 탭에 `incomplete` 클래스(주황 점 표시).
  - detail(): allScoredDone이 아니면 버튼 대신 안내(`.end-note`) 표시 — "아직 승패를 기록하지 않은 대진이 있어요. 라운드 버튼에 점이 있는 N,M라운드의 결과를 모두 입력하면 대진 종료 버튼이 나타나요." (미기록 라운드 번호 나열).
- `dist/server/boards-style.js`: `.round-tab.incomplete::after`(주황 점, 활성 탭은 흰 점), `.end-note`(연한 주황 안내 상자).

## 4. 검증 결과 (본체 + 로컬 브라우저 실동작)

- `node check-login.mjs` PASS.
- 미기록 상태(운영진): 탭 1R•2R•3R•4R(주황 점), 버튼 없음, 안내문 "…1, 2, 3, 4라운드…" 표시.
- 4경기 모두 기록 후: 점 사라짐, 안내 사라짐, '대진 종료' 버튼 등장.
- '대진 종료' 클릭 → 확인창 열림: 메시지 "정말 확정하시겠습니까? 확정하면 출석·승패 점수가 시드현황에 반영되고 되돌릴 수 없습니다.", 버튼 "예"/"아니오".
- "아니오" → 창 닫힘, 정산되지 않음(settledAt null) 확인. "예" → 정산.

## 5. 최종 점검 (Fable/본체)

- 버튼 미표시는 버그가 아니라 조건(운영진+전 라운드 기록) 문제였고, 라운드 탭 도입으로 미기록 라운드가 잘 안 보이던 것을 점 표시+안내로 해결.
- 확인창 문구는 "확정"(=마감)으로, 예/아니오 정상 동작. 문구를 "종료/마감"으로 바꾸는 것은 요청 시 반영.
