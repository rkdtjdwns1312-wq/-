# 게스트도 정산 점수 변동 대상 + 게스트→회원 이관

- 작업 시각: 2026-09-13 04:40 ~ 05:35 KST
- 작업 도구: Claude Code (Opus 4.8 본체 — 설계·구현·테스트·브라우저 하니스 검증). 실제 점수 데이터에 영향을 주는 정산 로직 변경이라 신중히 진행.
- 관련 요청: 068(게스트 정산 반영), 069(게스트→회원 이관)
- 사용자 확인(AskUserQuestion): MVP는 회원만 유지(기존 039). 이관 시 점수·출석·승·패 모두 그대로.

## 1. 요청 요약

- 068: 게스트도 회원과 마찬가지로 정산 때 점수가 바뀌게(출석 +1·승 +1·패 -1, 점수 누적, 점수 변동 화살표) 해달라.
- 069: 게스트가 정식 회원으로 가입할 수 있으니, 시드현황 수정 모드에서 체크 후 '회원으로 이관'하는 기능.

## 2. 수행 내용과 변경 파일

### 068 게스트 정산 반영
- `drizzle/0009_guest_scoring.sql`: guests 테이블에 attendance·wins·losses·previous_points 컬럼(previous_points는 현재 점수로 초기화) + guest_events 테이블(마감 취소 역산용, ranking_events에 대응).
- `dist/server/boards.js`:
  - settleSchedule: 참가자를 **회원/게스트로 정확히 한쪽만 판정**하는 통합 resolve(참가 id 우선, 없으면 이름; 회원 우선). 회원 델타(deltas)·게스트 델타(gDeltas)를 나눠 출석·승·패 반영(무효·랜덤 제외). 게스트도 points·previous_points·attendance·wins·losses 업데이트 + guest_events 기록. **MVP는 회원만**(resolve.t==='m').
  - unsettleSchedule: guest_events도 역산해 게스트 점수·출석·승·패 원복, guest_events 삭제.
  - 새 대진(version 0) 초기화: ranking_members와 함께 guests도 attendance/wins/losses=0, previous_points=points.
  - ensureGuests·게스트 추가 INSERT에 previous_points=points(신규 게스트 화살표 오작동 방지).
  - /api/people GET 게스트에 previous_points·attendance·wins·losses 포함.
- `dist/server/boards-client.js`: 시드현황 게스트 탭에 실제 출석·승·패 + 점수 변동 화살표(pointsMove). 안내문을 "게스트도 출석·승패로 점수 반영"으로 변경.

### 069 게스트→회원 이관
- `dist/server/boards.js`: POST /api/people/promote(운영진). 선택 게스트를 ranking_members로 INSERT(점수·출석·승·패 그대로, previous_points=points), guests는 hidden=1, 회원 순위 재정렬. 이름이 회원과 겹치면 409.
- `dist/server/boards-client.js`: 시드현황 수정 모드 게스트 탭에 '회원으로 이관' 버튼(회원 탭에선 hidden). promoteSelected()가 체크된 게스트 id로 promote 호출.

## 3. 검증 결과

- `node check-login.mjs` PASS. 추가 검증:
  - 게스트 추가 직후 previous_points=points, 출석 0.
  - 게스트가 이긴 정산 → 점수 30→32, previous_points=30, 출석 1·승 1·패 0. **MVP=['시오'](게스트 제외).**
  - 마감 취소 → 게스트 30·0·0·0 원복.
  - 재마감 후 회원으로 이관 → 게스트 목록에서 사라지고, 회원 랭킹에 점수 32·승 1·출석 1로 이관됨. promote 미인증 403.
- 브라우저 하니스: 게스트 탭에 아식스 112 ▲2(빨강)·출석1·승2, 허니 19 ▼1(파랑)·패1, 제냐 변동없음. 수정 모드에서 '회원으로 이관' 버튼이 게스트 탭에만 보이고 회원 탭에선 숨김, 게스트 행 체크박스 확인.
